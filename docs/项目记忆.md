# 项目记忆与坑位记录

只记录可复用坑位。每条固定使用“现象、原因、规避方式”，不写过程流水账。

## 后端与数据库

- 现象：Huma v2 的 Go adapter 包容易找错。原因：adapter 不在根包下。规避方式：使用 `github.com/danielgtaylor/huma/v2/adapters/humago`，配合 `huma.DefaultConfig`、`humago.New`、`huma.Register`。
- 现象：OpenAPI 文档入口容易误判为不存在。原因：Huma 默认已自动挂载 `/docs`、`/openapi.json`、`/schemas`。规避方式：除非明确调整路径，否则不重复手写文档路由。
- 现象：SQLite 依赖可能引入 CGO，影响 Windows/麒麟交叉编译。原因：传统 GORM SQLite driver 依赖 CGO。规避方式：统一使用 `github.com/glebarez/sqlite`，DSN 通过 `_pragma` 配置 `foreign_keys`、`journal_mode(WAL)`、`busy_timeout`。
- 现象：PowerShell 检查 JSON 时可能误报字符串不存在。原因：`Invoke-WebRequest.Content` 可能是 `byte[]`。规避方式：先判断类型，必要时用 UTF-8 解码后再检查。
- 现象：历史数据字段不符合当前编辑 schema 时，列表页仅切换启停也提示 `validation failed`。原因：前端把原有字段整包提交到 PUT，Huma 对旧数据中的非法字段重新执行完整校验。规避方式：创建与更新 schema 按需拆分；状态切换更新时允许空日期表示保留原值，业务层只在新增时强制必填。

## 前端工程

- 现象：项目级 npm 安装脚本被拒绝。原因：当前 npm 启用了项目级脚本白名单。规避方式：在 `web/package.json` 的 `allowScripts` 中白名单确需脚本的包，再普通安装；不传 `--allow-scripts`。
- 现象：React Router 相关包升级出现 `ERESOLVE`。原因：相关包通过 peer dependency 互相约束。规避方式：把 `react-router` 及配套包改到同一版本后一次性安装，不用 `--force` 掩盖冲突。
- 现象：React Router framework mode 文件路由显示空内容。原因：把 Data Mode 的 lazy `Component` 约定误用到 framework `routes.ts` 约定。规避方式：本项目固定使用 Data Mode + `createBrowserRouter`。
- 现象：依赖变化后页面卡在加载态。原因：Vite 预构建缓存过期或重建中，控制台出现 `504 Outdated Optimize Dep`。规避方式：重启 `npm run dev`，等待 re-optimize 完成。
- 现象：TypeScript 7 报 `baseUrl` 已移除。原因：TS7 删除该编译项。规避方式：删除 `baseUrl`，在 `paths` 中写相对 `tsconfig` 的映射。
- 现象：TanStack Table v9 用 v8 教程编译失败。原因：v9 改为 features 注册制，多个 API 改名。规避方式：按 v9 传入 `tableFeatures`、core/sorted row model 和对应类型参数；列助手也需要 features 类型。
- 现象：宽内容把 Grid 右列撑出视口。原因：`1fr` 隐式最小尺寸是 `min-content`。规避方式：主布局使用 `minmax(0, 1fr)`，表格容器用 `overflow-x-auto`。
- 现象：前后端冷启动后首次打开页面出现白屏。原因：Vite 开发模式按需编译，首次导航要请求并转换大量模块；`index.html` 的 `#root` 在 React 挂载前是空 DOM，`HydrateFallback` 只能覆盖挂载之后的加载。规避方式：`index.html` 内联零 JS 的预挂载首屏（React `createRoot` 接管 `#root` 后自动移除），并同步用预置脚本消除暗色主题闪白；生产构建首屏由代码分包和资源预加载覆盖。
- 现象：react-day-picker v10 日历 `captionLayout="dropdown"` 的年月下拉样式错乱。原因：v10 重构 DOM 和 classNames，shadcn v9 模板不能照抄。规避方式：使用 shadcn Select 年月头部 + 纯日期网格，保留 `mode="single"`，固定日历宽度和表格布局。
- 现象：CDP `CSS.getPlatformFontsForNode` 对有子元素的节点返回空数组。原因：该接口只统计节点直接文本渲染的字形。规避方式：先找到包含目标文字的叶子元素再查询。

## 前端视觉与交互

- 现象：`sonner` 成功提示浅色下背景偏红。原因：语义背景与无彩色弹层做 `color-mix` 插值时 hue 参与计算。规避方式：成功、警告、错误背景固定 `var(--popover)`，语义只放在边框和图标，并保持 `richColors` 开启。
- 现象：GSAP 循环动画重置时可见跳回。原因：动画起点仍在容器可见区。规避方式：循环首尾都放在不可见区域，必要时加 `repeatDelay`；动画只用 transform 和 opacity。
- 现象：Dialog 内嵌 Select 开闭时页面横向抖动。原因：两层 `react-remove-scroll` 锁定状态叠加导致滚动条消失又出现。规避方式：保留 `scrollbar-gutter: stable`，并在 Dialog/Select 开闭动画周期内恢复 body 的 overflow 和 margin。
- 现象：多层 `box-shadow` 状态切换像跳变。原因：基础态与激活态阴影层数不同，无法逐层插值。规避方式：默认、focus、错误态保持相同层数，并给颜色和阴影声明过渡。
- 现象：卡片 hover 时 Tailwind 阴影类看起来无效。原因：后加载的 `panel-surface` 基础阴影覆盖组件类阴影。规避方式：用稳定 `data-tone` / `data-risk-card` 属性在最终样式层定义基础、hover、深色阴影，并把边框轮廓拆到 outline 过渡。
- 现象：TanStack Table v9 反复提示 `sortFn 'text'/'alphanumeric' (auto) is not registered`。原因：v9 的 auto 排序不自动携带全部内置函数，features 只注册了别名。规避方式：同一个 `tableFeatures` 实例注册 `text`、`alphanumeric`、`basic`，业务表复用。
- 现象：Windows 下界面中文字体观感紧凑发闷，拉丁字符与数字回落系统字体。原因：字体栈把 `Microsoft YaHei UI` 放在标准 YaHei 前，且 Geist 未启用。规避方式：`Geist Variable` 放最前，删除 `Microsoft YaHei UI`，并在入口 import 字体包。
- 现象：一次性脚本拆分大 CSS 文件后，格式化工具将部分产物清空。原因：脚本未检查片段边界、选择器数量和花括号平衡，失败后也没有可回滚的中间校验。规避方式：优先用小补丁或带断言的 Node 脚本；拆分前后记录规则数与字节数，检查首尾选择器和括号平衡，完成后再跑构建与浏览器样式断言。
- 现象：`background-clip: text` 的渐变文字在部分动画相位下整体不可见。原因：渐变里使用 `currentColor`，而元素自身 `color: transparent`，`currentColor` 解析为全透明。规避方式：渐变文字的底色和高光用显式颜色或自定义属性表达，`currentColor` 只用于继承前景色的装饰元素；改动后用计算样式或截图验证各动画相位。

## 工具与跨会话

- 现象：安装大型 GitHub skill 仓库时长时间停在 clone。原因：只需要单个 skill 但拉取了整个仓库。规避方式：优先轻量来源；确需精确安装时用 raw 文件或精确路径，并维护 `skills-lock.json`。
- 现象：新会话找不到上次全局任务备忘。原因：只查看了记忆根目录，没查 `extensions/ad_hoc/notes/`。规避方式：开工先读 `srs/12-跨会话记忆.md`，并用 `rg` 搜索全局记忆全目录。
- 现象：Windows curl 访问 GitHub 报证书吊销检查失败。原因：schannel TLS 的 OCSP/CRL 检查被网络环境阻断。规避方式：加 `--ssl-no-revoke`；列仓库树用 GitHub API。
- 现象：apply_patch 对含中文路径环境下的既有文件反复匹配失败。原因：工具在中文路径环境下的行为限制。规避方式：优先拆小补丁；必要时先读全文再整文件替换，并确保锚点唯一。
- 现象：PowerShell 双引号字符串中的中文弯引号导致 ParserError。原因：PowerShell 把 Unicode 弯引号识别为字符串定界符。规避方式：包含弯引号的文本用单引号字符串。
- 现象：PowerShell 双引号字符串中的反引号使 Markdown 内容损坏。原因：反引号是 PowerShell 转义符。规避方式：包含反引号、`$` 或需保持字面的内容用单引号字符串或字面 here-string。
- 现象：Go 测试文件引用其他测试文件辅助函数报 undefined。原因：`package api` 与 `package api_test` 是两个包。规避方式：共用测试辅助函数时统一测试包名。
- 现象：npm install 后 `playwright-core` 从 `node_modules` 消失。原因：它原本是传递依赖且未显式声明，安装时被 prune。规避方式：项目实际使用的工具写入 package.json。
- 现象：在 `web/` 下用仓库根相对路径读写文件报不存在。原因：exec 工作目录随命令变化。规避方式：统一先切换到仓库根，或使用绝对路径。
- 现象：整页截图缩放后误判元素颜色。原因：缩略分辨率下色彩与位置混淆。规避方式：对可疑区域裁剪放大后再判断。
