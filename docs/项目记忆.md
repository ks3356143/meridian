# 项目记忆与坑位记录

只记录可复用坑位。每条固定使用“现象、原因、规避方式”，不写过程流水账。

## 后端与数据库

- 现象：Huma v2 的 Go adapter 包容易找错。原因：adapter 不在根包下。规避方式：使用 `github.com/danielgtaylor/huma/v2/adapters/humago`，配合 `huma.DefaultConfig`、`humago.New`、`huma.Register`。
- 现象：OpenAPI 文档入口容易误判为不存在。原因：Huma 默认已自动挂载 `/docs`、`/openapi.json`、`/schemas`。规避方式：除非明确调整路径，否则不重复手写文档路由。
- 现象：SQLite 依赖可能引入 CGO，影响 Windows/麒麟交叉编译。原因：传统 GORM SQLite driver 依赖 CGO。规避方式：统一使用 `github.com/glebarez/sqlite`，DSN 通过 `_pragma` 配置 `foreign_keys`、`journal_mode(WAL)`、`busy_timeout`。
- 现象：PowerShell 检查 JSON 时可能误报字符串不存在。原因：`Invoke-WebRequest.Content` 可能是 `byte[]`。规避方式：先判断类型，必要时用 UTF-8 解码后再检查。

## 前端工程

- 现象：项目级 npm 安装脚本被拒绝。原因：当前 npm 启用了项目级脚本白名单。规避方式：在 `web/package.json` 的 `allowScripts` 中白名单确需脚本的包，再普通安装；不传 `--allow-scripts`。
- 现象：React Router 相关包升级出现 `ERESOLVE`。原因：相关包通过 peer dependency 互相约束。规避方式：把 `react-router` 及配套包改到同一版本后一次性安装，不用 `--force` 掩盖冲突。
- 现象：React Router framework mode 文件路由显示空内容。原因：把 Data Mode 的 lazy `Component` 约定误用到 framework `routes.ts` 约定。规避方式：本项目固定使用 Data Mode + `createBrowserRouter`。
- 现象：依赖变化后页面卡在加载态。原因：Vite 预构建缓存过期或重建中，控制台出现 `504 Outdated Optimize Dep`。规避方式：重启 `npm run dev`，等待 re-optimize 完成。
- 现象：TypeScript 7 报 `baseUrl` 已移除。原因：TS7 删除该编译项。规避方式：删除 `baseUrl`，在 `paths` 中写相对 `tsconfig` 的映射。
- 现象：TanStack Table v9 用 v8 教程编译失败。原因：v9 改为 features 注册制，多个 API 改名。规避方式：按 v9 传入 `tableFeatures`、core/sorted row model 和对应类型参数；列助手也需要 features 类型。
- 现象：宽内容把 Grid 右列撑出视口。原因：`1fr` 隐式最小尺寸是 `min-content`。规避方式：主布局使用 `minmax(0, 1fr)`，表格容器用 `overflow-x-auto`。

- 现象：react-day-picker v10 日历 `captionLayout="dropdown"` 的年月下拉样式错乱，出现两个无样式原生 select。原因：v10 重构了下拉导航 DOM（`MonthCaption > Dropdowns > MonthsDropdown/YearsDropdown` 原生 select），不再有 `DropdownRoot`/`CaptionLabel` 包裹，且 classNames 键 `table` 改名 `month_grid`。规避方式：v10 每个下拉是 `rdp-dropdown_root` 包裹「原生 select + 展示 span」两层，select 默认不透明，必须把 `months_dropdown`/`years_dropdown` 设为 `absolute inset-0 opacity-0` 覆盖层、`dropdown_root` 设 relative 带边框、`caption_label`（展示 span）做可见层；导航行是绝对定位覆盖在 caption 上，`month_caption` 必须留出两侧导航按钮宽度（如 `px-9`）并给 `nav` 加 z 序，否则下拉行会盖住 `<` `>` 按钮；shadcn 的 calendar 模板按 v9 DOM 编写，升级 v10 不能照抄；v10 导航按钮 aria-label 是 "Go to the Previous Month"（带 the），与 v9 文本不同；透明 select 覆盖层方案在真实环境点击命中不可靠且样式难控，最终废弃，改为 shadcn Select 组合年月切换头部 + `hideNavigation` 纯日期网格（`YearMonthCalendar`）；封装转调 RDP 组件时必须保留 `mode`，漏传 `mode="single"` 会让 `isInteractive` 为假、日期渲染成纯文本无法选择；隐藏 caption 后需给日历固定宽度（w-72）+ `table-fixed`，否则弹层塌缩、网格溢出。
- 现象：CDP `CSS.getPlatformFontsForNode` 对有子元素的节点返回空数组。原因：该接口只统计节点直接文本渲染的字形。规避方式：先用 JS 找到包含目标文字的叶子元素再查询，才能取证真实渲染字体。
## 前端视觉与交互

- 现象：`sonner` 成功提示浅色下背景偏红。原因：`color-mix(in oklch, 绿色 14%, oklch(1 0 0))` 让无彩色 hue 参与插值，结果偏向红色。规避方式：与白色弹层混合时用 `color-mix(in srgb, ...)`，或给无彩色声明 missing hue。
- 现象：GSAP 循环动画重置时可见跳回。原因：动画起点仍在容器可见区。规避方式：循环首尾都放在不可见区域，必要时加 `repeatDelay`；动画只用 transform 和 opacity。
- 现象：Dialog 内嵌 Select 开闭时页面横向抖动。原因：两层 `react-remove-scroll` 锁定状态叠加导致滚动条消失又出现。规避方式：保留 `scrollbar-gutter: stable`，并在 Dialog/Select 开闭动画周期内恢复 body 的 overflow 和 margin。
- 现象：多层 `box-shadow` 状态切换像跳变。原因：基础态与激活态阴影层数不同，无法逐层插值。规避方式：默认、focus、错误态保持相同层数，并给颜色和阴影声明过渡。

- 现象：Windows 下界面中文字体观感比团队参考工具更紧凑发闷，拉丁字符与数字回落到 Segoe UI / Cascadia Mono。原因：`--font-sans` 把 `"Microsoft YaHei UI"` 排在标准 `"Microsoft YaHei"` 之前，中文字形被锁定到 UI 版（字面更窄更紧）；已安装的 `@fontsource-variable/geist` 没有在 `main.tsx` import，等于没启用。规避方式：字体栈把 `"Geist Variable"` 放最前承接拉丁与数字，删除 `Microsoft YaHei UI` 让中文回退标准 YaHei；需要时用 CDP `CSS.getPlatformFontsForNode` 取证实际渲染字体。

## 工具与跨会话

- 现象：安装大型 GitHub skill 仓库时长时间停在 clone。原因：只需要单个 skill 但拉取了整个仓库。规避方式：优先轻量来源；确需精确安装时用 raw 文件或精确路径，并维护 `skills-lock.json`。
- 现象：新会话找不到上次全局任务备忘。原因：只查看了记忆根目录，没查 `extensions/ad_hoc/notes/`。规避方式：开工先读 `srs/12-跨会话记忆.md`，并用 `rg` 搜索全局记忆全目录。
- 现象：Windows curl 访问 GitHub 报证书吊销检查失败。原因：schannel TLS 的 OCSP/CRL 检查被网络环境阻断，不是登录问题。规避方式：加 `--ssl-no-revoke`；列仓库树用 GitHub API。
- 现象：apply_patch 对含中文内容的工作区文件反复匹配失败（连纯 ASCII 行也会失败），同一文件多操作批量补丁报 invalid patch: multiple operations target。原因：该工具在中文路径环境下的行为限制。规避方式：用 PowerShell `[System.IO.File]::ReadAllText/WriteAllText`（UTF-8 无 BOM 写回）做精确替换，替换前先统计锚点出现次数必须等于 1；新建文件用字面 here-string 写入。
- 现象：PowerShell 双引号字符串中的中文弯引号（“”）导致 ParserError，字符串被弯引号提前截断。原因：PowerShell 把 Unicode 弯引号识别为字符串定界符。规避方式：包含弯引号的文本一律用单引号字符串。
- 现象：PowerShell 双引号字符串中的反引号使 Markdown 内容损坏，如 `r` 被转义成回车。原因：反引号是 PowerShell 转义符。规避方式：包含反引号、`$` 或需要保持字面的内容用单引号字符串或 `@'...'@` 字面 here-string。
- 现象：Go 测试文件引用其他测试文件的辅助函数报 undefined。原因：`package api` 与 `package api_test` 是两个包，外部测试包看不到内部测试包的标识符。规避方式：需要共用测试辅助函数时统一使用同一测试包名。
- 现象：npm install 后 playwright-core 等工具从 node_modules 消失。原因：它原本是残留的传递依赖，未被显式声明，npm 安装时被 prune。规避方式：项目实际使用的工具必须写入 package.json（如 playwright-core 进 devDependencies）。
- 现象：在 web/ 工作目录下用仓库根相对路径（如 web/src/...）读写文件报路径不存在。原因：exec 工作目录随命令变化，相对路径基于当前目录解析。规避方式：统一先用 `Set-Location` 到仓库根，或直接使用绝对路径。
- 现象：整页截图缩放后误判元素颜色（相邻错误框干扰判断）。原因：缩略分辨率下色彩与位置混淆。规避方式：对可疑区域先裁剪放大（System.Drawing）再下结论。
