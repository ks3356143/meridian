## 高频结论（多数情况读到这里就够）

- **直角体系**：`web/src` 内不得出现 `rounded-md/lg/xl/2xl/3xl`；圆角只允许 0–2px，圆点与胶囊除外。
- **滚动职责单一**：工作区由 `main.workspace-route` 承担唯一纵向滚动；表格内层只负责横向滚动，必须显式 `overflow-y:hidden`；非虚拟化表格不要写 `overscroll-behavior:contain`，会锁死滚轮。
- **活动指示器贴边**：左侧活动轨 `inset-block:0` 满行高；Tab 下划线 `left:0; right:0` 铺满；溢出用 `justify-center-safe`，禁止裸 `justify-center` + `overflow-x:auto`。
- **闪光只播一次**：装饰性扫光一律 `animation-iteration-count:1` 并移出可见区；循环只保留 spinner / 骨架 / 荧光呼吸 / 光标闪烁。
- **输入焦点唯一事实源**：`web/src/styles/field-state.css`，组件里再写 Tailwind `shadow-[]` 是死代码。
- **图标按钮必须正方形**：文字收起后要在同一断点把 `width` 对齐高度，验收量 `getBoundingClientRect()`。
