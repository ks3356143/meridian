# 项目记忆：前端视觉与交互

> 返回 [项目记忆索引](../项目记忆.md)

## 前端视觉与交互

- 现象：独立项目工作区在桌面端内容超出视口后底部不可见，作业台、资料与对象等页面没有滚动条。原因：外层 `workspace-shell` 使用 `h-svh + overflow hidden`，而主内容 `main.workspace-route` 的纵向滚动只写在 1100px 以下媒体查询里，桌面端没有任何滚动祖先。规避方式：`main.workspace-route` 在全部宽度承担工作区唯一主纵向滚动；有内部作业树的模块（如需求与追踪）内部继续声明 `height: 100% / min-height: 0`，让树自己滚动并保持路由 `scrollHeight <= clientHeight`，不要把滚动规则只挂在窄屏分支。
- 现象：前端设计时技能选错，出现风格不统一或评审口径混乱。原因：没有固定的技能优先级顺序。规避方式：前端设计类任务按固定顺序使用技能——先 `design-taste-frontend` / `frontend-design` 定风格与品味，再用 `ui-ux-pro-max` 查设计系统与 UX 规则落地细节。
- 现象：`sonner` 成功提示浅色下背景偏红。原因：语义背景与无彩色弹层做 `color-mix` 插值时 hue 参与计算。规避方式：成功、警告、错误背景固定 `var(--popover)`，语义只放在边框和图标，并保持 `richColors` 开启。
- 现象：GSAP 循环动画重置时可见跳回。原因：动画起点仍在容器可见区。规避方式：循环首尾都放在不可见区域，必要时加 `repeatDelay`；动画只用 transform 和 opacity。
- 现象：Dialog 内嵌 Select 开闭时页面横向抖动。原因：两层 `react-remove-scroll` 锁定状态叠加导致滚动条消失又出现。规避方式：保留 `scrollbar-gutter: stable`，并在 Dialog/Select 开闭动画周期内恢复 body 的 overflow 和 margin。
- 现象：多层 `box-shadow` 状态切换像跳变。原因：基础态与激活态阴影层数不同，无法逐层插值。规避方式：默认、focus、错误态保持相同层数，并给颜色和阴影声明过渡。
- 现象：字段错误修正后提示瞬间消失，入场展开动画无法对称收起。原因：调用方使用条件渲染，错误一变空就卸载 `FieldError`，退出动画没有可播放的 DOM 宿主。规避方式：表单始终渲染 `FieldError` 并传入当前错误，由组件保留最后一帧错误内容播放淡出与高度收起，动画结束后再卸载。
- 现象：批量替换未输入查找词、只输入替换词时，预览把名称和标识的每个字符都标成替换结果。原因：空字符串执行 `split("")` 会拆成单字符数组，预览构建误把空查找词当成有效关键词。规避方式：空查找词视为替换未启用，预览和提交载荷都短路；同时保留字段必填星号、失焦错误和提交禁用反馈。
- 现象：详情或弹窗中的副类型多选触发器为与其他下拉框等高而固定高度，窄屏选中多个标签换行后内容被裁切。原因：多选标签容器可换行，但触发器高度被固定。规避方式：默认用 `min-height` 与普通下拉对齐，`height: auto` 允许多标签自然撑开；单行态和 320px 多标签态都要用浏览器尺寸断言验证。
- 现象：卡片 hover 时 Tailwind 阴影类看起来无效。原因：后加载的 `panel-surface` 基础阴影覆盖组件类阴影。规避方式：用稳定 `data-tone` / `data-risk-card` 属性在最终样式层定义基础、hover、深色阴影，并把边框轮廓拆到 outline 过渡。
- 现象：TanStack Table v9 反复提示 `sortFn 'text'/'alphanumeric' (auto) is not registered`。原因：v9 的 auto 排序不自动携带全部内置函数，features 只注册了别名。规避方式：同一个 `tableFeatures` 实例注册 `text`、`alphanumeric`、`basic`，业务表复用。
- 现象：Windows 下界面中文字体观感紧凑发闷，拉丁字符与数字回落系统字体。原因：字体栈把 `Microsoft YaHei UI` 放在标准 YaHei 前，且 Geist 未启用。规避方式：`Geist Variable` 放最前，删除 `Microsoft YaHei UI`，并在入口 import 字体包。
- 现象：一次性脚本拆分大 CSS 文件后，格式化工具将部分产物清空。原因：脚本未检查片段边界、选择器数量和花括号平衡，失败后也没有可回滚的中间校验。规避方式：优先用小补丁或带断言的 Node 脚本；拆分前后记录规则数与字节数，检查首尾选择器和括号平衡，完成后再跑构建与浏览器样式断言。
- 现象：`background-clip: text` 的渐变文字在部分动画相位下整体不可见。原因：渐变里使用 `currentColor`，而元素自身 `color: transparent`，`currentColor` 解析为全透明。规避方式：渐变文字的底色和高光用显式颜色或自定义属性表达，`currentColor` 只用于继承前景色的装饰元素；改动后用计算样式或截图验证各动画相位。
- 现象：工作区路由切换时滚动条看起来先出现再消失。原因：路由和卡片入场动画做纵向位移，临界高度下会把内容推出滚动边界；未统一的内部滚动条还会回落到浏览器默认样式。规避方式：工作区入场动画只改透明度，模块内滚动条统一 8px 直角主题样式，并用逐帧 DOM 检查确认 transform 为 `none`。
- 现象：需求树行数增多后在左栏出现纵向滚动条，树面板没有贴到工作区底部。原因：独立项目工作区路由外层没有可继承高度，`h-full` 按内容高度解析；需求工作台又用 `100svh` 减固定偏移估算高度，左侧 Tabs 内容层和 `react-arborist` 高度也被固定值截断。规避方式：独立工作区外壳直接使用 `h-svh`，内部逐级 `flex-1`、`min-h: 0`、`height: 100%`，仅让树内容区自身滚动；树高度取容器实际 `clientHeight`，不要再设置会撑破父级的固定最小值。
- 现象：需求删除与彻底删除弹窗都关闭时 React 反复警告 duplicate key `none`。原因：两个常驻弹窗都在关闭态使用同一个 fallback key。规避方式：多个同类弹窗的 fallback key 加业务前缀，例如 `delete-none`、`purge-none`。
- 现象：`react-arborist` 展开收缩时子行瞬移、文字闪回或出现横向滚动条。原因：组件未内置展开动画，虚拟列表在状态变化后会立即重算 DOM；额外使用 `absolute` 或逐行 `clearProps` 会扰动定位并让行提前恢复显示。规避方式：使用 GSAP Flip 处理存量行位移，折叠先等待整组真实行淡出，再 `flushSync` close 并统一清理样式；不启用 `absolute`，新增行只淡入，脚本通过稳定 `data-*` 标记定位，`prefers-reduced-motion` 下直接切换。
- 现象：删除需求时淡出动画落在已分离的旧行。原因：选中项变化导致行渲染函数身份变化，React 更换行 DOM。规避方式：行事件通过 ref 传递并保持 renderer 稳定，删除成功后先对当前真实行淡出，再刷新工作台数据。
- 现象：窄屏需求工作台上下排列后出现路由、树、详情多层滚动条。原因：外层 `h-svh + overflow hidden` 只能裁切，内部又分别给树和详情固定高度，形成嵌套滚动。规避方式：1100px 以下只保留工作区路由一个主纵向滚动，`react-arborist` 按当前展开内容传自然高度，统计和详情正文随内容展开；仅多行文本达到最大高度或表格真实横向溢出时允许局部滚动。
- 现象：自动增高 Textarea 在窄屏空内容时也涨到最大高度。原因：`react-textarea-autosize` 会用 placeholder 参与高度计算，长占位文案在窄容器中多次换行。规避方式：统一组件设置 `minRows/maxRows` 并禁用拖拽手柄，已有标签的场景不依赖长占位文案；需求描述 5 到 12 行，删除原因 3 到 6 行，超过上限后内部滚动。
