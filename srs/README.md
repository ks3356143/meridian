## 维护规则

- 新需求先落文件，再进入实现。
- 单个文件只记录一个主题，超过约 200 行时继续拆分。
- 未确定的内容写入《需求状态》，不提前固化。
- 已确定的技术和流程变化必须同步到对应主题文件。
