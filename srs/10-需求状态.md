# 需求状态

## 已确定

- 本地绿色版形态。
- 后端技术路线。
- 前端使用 Vite + React Router 8 SPA Data Mode。
- 前端目录使用传统 `web/src`。
- 浅色为默认主题，支持深浅色切换。
- UUIDv7 主键策略。
- API 按业务域模块化。
- 认证采用 bcrypt + JWT + Casbin。
- Word 生成采用原始 DOCX + OOXML 渲染。
- 项目是全部测评流程的基点；项目创建需确定标识、测评性质、测试平台、软件类型、密级、安全等级、技术字典、依据标准和人员。
- 技术字典与依据标准采用字典化维护，项目创建时选择并保存关联。

## 已实现

- 后端最小服务。
- SQLite 连接、显式迁移和健康检查。
- 用户表、初始管理员、JWT 登录和 `/auth/me`。
- Casbin RBAC 中间件。
- 前端工程、登录页、工作台占位页和真实登录流程。
- `sonner` 全局提示。
- 浅色默认主题和深色切换。
- 项目、基础字典、依据标准、项目成员及关联表迁移。
- 项目创建选项、创建、列表和详情 API。
- `/projects/new` 真实项目创建页。
- `/settings/dictionaries` 技术字典与依据标准管理页，支持新增、编辑、启停和排序。
- 首页项目列表与项目工作台已接入真实项目 API，mock 数据已删除。

## 待确认

- 多被测系统的项目层级。
- Word 模板特殊格式点。
- 测试人员、环境、结论模型。
- 用户管理、角色管理和修改密码规则。

## 视觉优化待办

- 首页整体现代感与炫酷度升级：当前 KPI 条与表格偏“表格工具”，需要更高级的视觉层次。
- 优先复用本地项目级 skills：high-end-visual-design、design-taste-frontend、ui-ux-pro-max、frontend-design。
- 方向候选：KPI 条改为更有张力的数据展示、表格行 hover 与状态视觉强化、首页顶部加轻量活动流或里程碑时间线、深色模式下的辉光层次增强。
- 改造仍需遵守 srs/07-前端体验.md 的视觉动效规范（直角、匀速流光、reduced-motion）。
- 同步升级全局控件质感：按钮、输入框、卡片与状态标签采用 Material 式主题阴影和交互反馈，但不引入 MUI。
