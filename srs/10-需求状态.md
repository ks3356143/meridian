# 需求状态

## 已确定

- 本地绿色版形态。
- 后端技术路线。
- 前端使用 Vite + React Router 8 SPA Data Mode。
- 前端目录使用传统 `web/src`。
- 浅色为默认主题，支持深浅色切换。
- UUIDv7 主键策略。
- API 按业务域模块化。
- 认证采用 bcrypt + JWT，无全局角色。
- Word 生成采用原始 DOCX + OOXML 渲染。
- 项目是全部测评流程的基点；项目创建需确定标识、测评性质、测试平台、软件类型、密级、安全等级、技术字典、依据标准和人员。
- 技术字典与依据标准采用字典化维护，项目创建时选择并保存关联。
- 项目详情保留在系统后台；项目工作区是独立全屏路由，采用“一级导航 + 模块二级导航”，业务模块独立拆分。
- 项目创建成功后自动创建第 1 轮；轮次是范围和执行快照，不是所有数据的父节点。
- 富文本采用 Tiptap JSON 权威源，保存为 SQLite TEXT；Word 生成直接做受限 JSON 到 OOXML 映射。
- 附件文件存程序数据目录，SQLite 保存元数据和哈希，不在正文中保存 base64。
- 知识库 7 份模板映射为五类文档种类，测试说明和测试记录随轮次生成多个实例。
- 数据按基准数据、章节内容块、过程数据、关联数据、专项证据数据集、单源片段、派生统计和输出快照分类。
- 项目特殊的大规模证据数据通过可登记数据集能力承载，不转换为测试项或用例。
- 轮次保存输入基线，并区分静态与动态阶段。
- 问题缺陷和对外报告单分层，一个报告单可聚合多个缺陷。
- 录入体验遵循“能默认不手填、能继承不重敲、能批量不逐条、能键盘不鼠标、能就地不跳转”。
- Word 生成采用模板大纲、数据资源字典、内置渲染积木、复杂表格带区、叙述占位和导入比对组合。

## 已实现

- 后端最小服务。
- SQLite 连接、显式迁移和健康检查。
- 用户表、固定系统管理员、JWT 登录、`/auth/me` 和用户管理接口。
- 前端工程、登录页、工作区占位页和真实登录流程。
- `sonner` 全局提示。
- 浅色默认主题和深色切换。
- 项目、基础字典、依据标准、项目成员及关联表迁移。
- 项目创建选项、创建、列表和详情 API。
- `/projects/new` 真实项目创建页。
- `/settings/dictionaries` 技术字典与依据标准管理页，支持新增、编辑、启停和排序。
- `/settings/users` 用户管理页，支持新增、编辑、删除和系统管理员保护。
- 首页项目列表、项目详情与项目工作区已接入真实项目 API，mock 数据已删除。
- 项目工作区首版壳已实现：独立全屏顶栏、一级导航、全局轮次占位切换器、9 个路由化分区和模块化二级导航占位页。
- 大纲编制流首版已实现：项目按阶段自动进入大纲页，提供大纲目录树、章节任务、下一步录入和文档预检入口。
- 全局 Material 式控件质感、输入 focus/error 荧光状态、移动端抽屉导航和基础页面动效。
