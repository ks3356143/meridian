# 数据与 ID

## 主键

所有业务表主键统一使用 UUIDv7 字符串，由 Go 应用统一生成。

约定：

- SQLite 中使用 `TEXT PRIMARY KEY` 存储 36 位标准字符串。
- ID 生成入口统一收敛，不允许各模块自行选择 ID 策略。
- UUIDv7 提供时间有序性，但不作为业务时间。
- 所有表保留 `created_at`、`updated_at` 字段。

## 说明

UUIDv7 不是严格自增，也不承诺绝对不冲突；它的价值在于时间有序、离线可生成、索引写入比 UUIDv4 友好。

## 迁移

- 迁移脚本放在 `migrations/`。
- 每个迁移包含 up/down SQL。
- 后端启动时自动执行未应用的 up 迁移。
- 已应用版本记录在 `schema_migrations` 表。
