# 前端体验

## 视觉方向

默认使用浅色工程风格，支持切换深色主题。

界面保持直角、细边框、高密度、清晰层级和克制的绿色状态色。避免圆润卡片堆叠、单一蓝紫渐变和营销页式布局。

全局控件采用 Material 质感语言，但不引入 MUI 组件库：按钮、输入框、卡片和标签使用主题感知阴影、颜色和边框反馈；直角仍是主规则，控件最多 2px 微圆角。质感反馈可以动画阴影、颜色和边框，动效优先服务“好看、清晰、有层级”。
界面与小号文字统一使用系统字体栈：`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`，中文自动回退到 Microsoft YaHei；数字和标识数据使用等宽字体，避免表格列宽跳动。

按钮必须有 pointer 位置触发的点击水波纹，并有 hover 阴影增强和 active 轻微下沉反馈。按钮与下拉框 hover 状态禁止位移，只允许边框、颜色、背景和阴影变化。选项下拉使用 shadcn/Radix Select 体系，弹层、选中态、键盘导航和入场动画保持组件库体验。Tabs 使用 shadcn/Radix Tabs 标准结构，active 状态使用组件库的背景块与阴影，不使用自造滑块造成溢出。

表格表头默认水平居中，数值、状态、标签、操作等短列必须居中；项目名称、描述等长文本列可在确需左对齐扫描时例外，但同一表格内必须形成清晰对齐规则。

## 组件库铁律

Select 打开和关闭过渡期间页面纵向滚动条必须保持可见，布局宽度不得变化。

标签使用 shadcn/Radix Badge 体系，不同语义变体必须保持一致尺寸；颜色、边框和 hover 可以区分语义，但不得通过外扩阴影制造视觉高度差。

能使用成熟组件库的交互组件必须使用组件库：项目内优先 shadcn/ui 与 Radix UI；表格、路由、数据等场景使用 TanStack、React Router 等对应专业组件库。仅纯展示、布局或确无组件库能力时允许手写，且必须补齐无障碍、键盘操作、焦点态和微动效。新增交互组件前先检查 `web/src/components/ui` 是否已有对应组件，再做实现决策。

## 目录结构

前端位于 `web/src`，使用传统 Vite SPA 结构：

- `src/api/`：HTTP 客户端和接口封装。
- `src/components/provider/`：全局 Provider。
- `src/components/router-util/`：路由加载和错误状态。
- `src/components/ui/`：shadcn/ui 生成的基础组件。
- `src/features/<模块>/`：业务模块，内部继续拆 `api.ts`、`types.ts`、`components/`。
- `src/layouts/`：页面布局。
- `src/lib/`：GSAP 等通用能力。
- `src/pages/`：路由页面组件。
- `src/router/`：`createBrowserRouter` 路由定义。
- `src/stores/`：Zustand 状态。
- `src/styles/`：全局样式。

后续新增模块优先放入 `features/`，不把业务代码混入基础组件目录。

## 路由模式

- 使用 React Router 8 SPA Data Mode。
- 使用 `createBrowserRouter` + `RouterProvider`。
- 路由页面支持 lazy 加载。
- 页面模块按 React Router Data Mode 约定导出 `Component`。
- 认证判断放在布局或页面组件中，后续可扩展 loader 和 action。

## 动画

- 使用 GSAP 和 `useGSAP` 管理动画生命周期。
- 动画快速、精致，优先突出层级和状态。
- 必须尊重 `prefers-reduced-motion`。
- 动画不得拖慢录入效率。

## 登录页

- 首屏即登录表单，不做营销落地页。
- 左侧展示服务、SQLite、认证和运行模式状态。
- 右侧为高密度登录表单。
- 登录失败在表单附近给出明确错误。
- 登录成功进入工作台。

## 反馈

- 操作成功、失败和网络异常统一使用 `sonner` 提示，全局位置固定为顶部居中。
- 表单字段校验错误保留在字段附近。
- 401 时清理本地登录态并回到登录页。

## 视觉动效规范

品牌视觉以“经线”（Meridian）为核心意象：经线球体线框、匀速流光、信号传递流程条构成统一的动效语言。绿色为主状态色，炫彩渐变仅用于品牌字标和页面主标题，不扩散到正文和控件。

### 品牌元素

- 品牌图标：经线球体（外圆 + 经线椭圆 + 纬线）叠加测试准星（四向延伸线 + 中心测试点方块），直角收尾。
- 图标复用：`web/src/components/brand/logo.tsx` 的 BrandLogo（currentColor），登录页左上角、侧边栏、favicon 同源。
- favicon：`web/public/favicon.svg` + `favicon.ico`（16/32/48），`index.html` 先 SVG 后 ICO。

### 登录页动效

- 左侧品牌字标：逐字符 stagger 上浮入场（`yPercent: 70 -> 0`）。
- 炫彩字标：逐字符 `background-clip: text` + 连续多色渐变（`backgroundSize` / `backgroundPositionX` 偏移保证跨字符连续），14 秒 hue-rotate 慢转；浅深色各一套 `--wordmark-gradient`。
- 经线流光：字标下方 1px 线上一条辉光光带匀速滑过（`ease: none`，5.2 秒一轮，间隔 0.5 秒）。
- 流程信号传递：测试项 -> 用例 -> 执行 -> 报告四节点三段连接线，光带匀速接力；光带抵达时节点点亮，离开后熄灭，任意时刻只有一个节点发光。
- 背景光斑：两个 primary 径向光斑 4.8 秒呼吸（yoyo + scale）。
- 经线球线框：右上角嵌套椭圆 SVG 线框，70 秒匀速旋转。
- 按钮：hover 白色光泽扫过（`btn-sheen`，0.7 秒 cubic-bezier）。

### 工作台动效

- 页面主标题复用炫彩渐变（静态，不转 hue）。
- 标题下一条匀速流光线（4.5 秒一轮，间隔 0.8 秒）。
- 指标条 stagger 入场；数字指标从 0 滚动到目标值（snap 取整）。
- 指标 hover：边框、阴影和图标同时反馈，形成上浮质感。
- 右上角经线球线框装饰（primary/5）。

### 动效规则

- 循环动画的起点和终点必须在容器外不可见区域，循环重置不允许可见跳变。
- 流光类动效一律匀速（`ease: none`）。
- 动效优先服务质感与状态表达，可以使用 transform、opacity、filter、box-shadow、color、background-color、border-color；仅禁止动画 width、height、top、left 等明显触发布局的属性。
- 阴影、颜色、边框等质感过渡时长 180-260ms，hover / focus 反馈必须清晰。
- 按钮和下拉框 hover 禁止位移，反馈只使用边框、颜色、背景和阴影；active 可保留 1px 内的按压位移。
- 非必要循环动画在 `prefers-reduced-motion: reduce` 下关闭；一次性 hover / focus 反馈可保留但去掉位移。
- 动效不得阻塞操作路径，表单和按钮响应优先。

全局使用传统语义色体系：主题色与成功色为绿色，警告色为橙色，错误/危险色为红色，信息色为蓝色或中性色。品牌绿只代表主品牌和主操作，不得让警告、危险、停用、信息也统一变成绿色；语义状态必须优先使用对应语义色。
字典、依据标准等启用/停用状态必须一眼可辨：启用使用 success 绿色并搭配确认图标，停用使用中性色并搭配关闭图标。`sonner` 提示必须按结果选择语义：成功用 success，停用/需注意用 warning，失败用 error，说明性信息用 info。
