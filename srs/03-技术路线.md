# 技术路线

## 后端

- Go
- Huma v2
- GORM
- SQLite
- SQLite 驱动使用 `github.com/glebarez/sqlite`，保持 pure Go 路线，避免 CGO。
- 数据库结构使用显式 migration，不长期依赖 AutoMigrate。
- 数据库、附件、模板、报告等运行数据使用程序目录下的相对路径。

## 前端

- Vite
- React
- React Router 8 SPA Data Mode，使用 `createBrowserRouter` + `RouterProvider`。
- 不使用 React Router framework mode 的 `routes.ts` 文件约定。
- 前端源码使用传统 `web/src` 目录。
- Tailwind CSS v4
- shadcn/ui + Radix UI
- Zustand
- TanStack Query
- TanStack Table
- GSAP + `@gsap/react`
- `lucide-react`
- `cmdk`
- `sonner`
- 前端检查使用 OXC 工具链：`oxlint` 负责 lint，`oxfmt` 负责格式化。

## 版本要求

依赖版本跟随当前最新稳定版。React Router 相关包必须保持同一版本，TypeScript 使用当前最新稳定版。

## 主题

默认使用浅色主题，界面上提供明确的深浅色切换；深色主题保留，但不作为默认形态。

## 交叉编译

- 优先选择 pure Go 依赖，确保 Windows 与麒麟 V10 可携带运行。
- 不引入依赖 CGO 的本地库。
