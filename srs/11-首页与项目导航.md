# 首页与项目导航

## 信息架构

- `/`：项目列表页（应用首页），以多项目为中心，一眼看清全部在跑的项目。
- `/projects/new`：真实项目创建页。
- `/projects/:id`：项目工作台，单项目大页面，承载该项目的测试项、用例、执行记录、问题单、文档产出。
- 登录后默认进入 `/`；点击项目行进入对应工作台。
- 桌面端使用固定左侧导航；窄屏隐藏侧栏时，顶栏必须保留小菜单按钮，点击后以左侧抽屉展示同一套导航，点击导航项后自动关闭。
- 工作台是独立的“大页面”，不在首页内嵌；后续功能模块都挂在项目工作台下。

## 首页（项目列表）布局

1. 顶栏（一行）：页面标题 + 日期 + 快捷操作（新建项目、生成文档占位）。
2. 筛选条：关键词（标识、名称、研制单位、负责人）+ 状态、等级、平台筛选；筛选状态保存到 localStorage，展示结果数量并支持一键清空。
3. KPI 密排条：一行 6 个微型指标（数字 + 小标签），不使用大卡片。指标包括：项目总数、执行中、编制中、已完成、用例执行率、未闭环问题（重大/严重红色高亮），并补充执行率微进度与问题级别拆解。
4. 风险与活动摘要条：仅从项目字段推导，重大/严重未闭环问题优先，其次未闭环总数与待执行用例；点击条目进入项目工作台。
5. 项目表（主体）：TanStack Table 分列展示，紧凑行高（约 44px），一屏 15 行以上。列：标识、项目名称、测评性质、软件类型、安全等级、平台、研制单位、负责人、用例执行（n/m）、未闭环问题、状态、更新时间。支持排序、键盘 Enter 导航与左侧 hover 指示线；点击行进入项目工作台。
6. 右侧栏（约 320px）：我的待办（未闭环问题 Top5、待执行用例、最近更新项目）。
7. 视觉延续品牌动效规范：经线球背景装饰、匀速流光分隔线、面板 hover 辉光、入场 stagger、数字滚动。

首页统计口径：KPI、风险摘要、待办栏和项目表均跟随当前筛选结果；页面标题、日期和快捷操作不参与筛选。生成文档保持占位操作；新建项目跳转到真实项目创建流程，字段口径见《13-项目创建与基础字典》。

## 项目数据模型

- 项目标识：`R` + 4 到 5 位数字，创建时用户输入数字后缀，前缀 `R` 固定。
- 测评性质：鉴定测评 / 第三方测评 / 二方测评。
- 测试平台：FPGA / CPU/非嵌。
- 软件类型：新研 / 改造 / 沿用。
- 密级：公开 / 内部 / 秘密 / 机密 / 绝密。
- 安全等级：关键A / 重要B / 一般C / 不重要D。
- 编程语言、运行环境、开发环境、依据标准、负责人和成员口径见《13-项目创建与基础字典》。
- 状态机：编制大纲中 → 大纲已评审 → 测试执行中 → 回归验证中 → 报告编制中 → 已完成。
- 用例执行：`已执行/总数` 与百分比。
- 问题单：未闭环数量按级别（重大/严重/一般/建议改进）统计。

## 项目工作台

- 顶部：项目标识 + 名称 + 状态 + 关键属性标签 + 返回。
- 主体分区：概览、测试项、用例、执行记录、问题单、文档产出。
- 概览展示项目基础信息、依据标准、成员和模块统计。
- 测试项、用例、执行记录、问题单、文档产出待项目流程推进后接入。
