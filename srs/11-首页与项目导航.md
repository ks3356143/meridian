# 首页与项目导航

## 信息架构

- `/`：项目组合页（应用首页），以多项目为中心，一眼看清全部在跑的项目。
- `/projects/:id`：项目工作台，单项目大页面，承载该项目的测试项、用例、执行记录、问题单、文档产出。
- 登录后默认进入 `/`；点击项目行进入对应工作台。
- 工作台是独立的"大页面"，不在首页内嵌；后续功能模块（用例库、执行记录、报告生成）都挂在项目工作台下。

## 首页（项目组合）布局

1. 顶栏（一行）：页面标题 + 日期 + 快捷操作（新建项目、生成文档占位）。
2. KPI 密排条：一行 6 个以上微型指标（数字 + 小标签），不使用大卡片。指标包括：项目总数、执行中、编制中、已完成、用例执行率、未闭环问题（重大/严重红色高亮）。
3. 项目表（主体）：TanStack Table 分列展示，紧凑行高（约 44px），一屏 15 行以上。列：标识、项目名称、测评性质、测试类型、安全等级、平台、研制单位、负责人、用例执行（n/m）、未闭环问题、状态、更新时间。支持排序；点击行进入项目工作台。
4. 右侧栏（约 320px）：我的待办（未闭环问题 Top5、待执行用例、最近更新项目）。
5. 视觉延续品牌动效规范：经线球背景装饰、匀速流光分隔线、卡片 hover 辉光、入场 stagger、数字滚动。

## 项目数据模型（源自 knowledge-base 文档模板）

- 项目标识：`R26xx` 形式编号。
- 测评性质：鉴定测试 / 第三方测试 / 分析评测。
- 测试类型：配置项测试 / 系统测试。
- 安全等级：A / B / C / D。
- 平台：CPU / FPGA / 桌面。
- 状态机：编制大纲中 → 大纲已评审 → 测试执行中 → 回归验证中 → 报告编制中 → 已完成。
- 用例执行：`已执行/总数` 与百分比。
- 问题单：未闭环数量按级别（重大/严重/一般/建议改进）统计。

## 项目工作台（骨架约定）

- 顶部：项目标识 + 名称 + 状态 + 关键属性标签 + 返回。
- 主体分区（Tab 或分区导航）：概览、测试项、用例、执行记录、问题单、文档产出。
- V0.0.1 先实现概览骨架与导航结构，业务模块逐个填充。
