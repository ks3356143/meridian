# 版本、预检与约束

> 返回 [七类文档数据映射](../17-七类文档数据映射.md)

## 版本与锁定

- TO、TR 为外部评审文档：初版 `V1.00`，评审后重新生成升 `V1.10`，再次生成时用户选择保持或升级。
- TD、TN、回归系列和问题单合集恒为 `V1.00`，重新生成只追加文件状态记录。
- 文档生成时固化模板快照和数据快照；已锁定文档不被模板和数据修改影响。
- 单源片段若被系统声明为共享语义资产，修改后可影响后续生成，但必须提示受影响文档。
- 定稿锁定可逆，解锁记录操作者、时间和原因。
- 支持一键打包下载全部已生成且状态正常的文档。

## 导入与回流

- 支持从外部 DOCX 导入软件概述、报告叙述、问题单处理意见等章节。
- 导入采用比对采纳：平台现状与外部内容分栏展示、差异高亮、逐块保留或采纳。
- 未匹配章节只展示，不自动入库。
- 研制方回流的问题单 DOCX 可导入处理意见、原因分析、改正措施和影响域，再进入回归验证。
- 导入来源、采纳时间和采纳人写入内容块变更记录。

## 预检规则

| 文档 | 必查项 |
| --- | --- |
| 测评大纲 | 项目基础、相关方、依据文件、被测对象、静态环境、动态环境、测试项、时间锚点。 |
| 测试说明 / 回归测试说明 | 当轮环境、测评数据、差异分析、轮次范围、用例定义、需求追踪；回归轮另查软件更改。 |
| 测试记录 / 回归测试记录 | 当轮执行结果、步骤实测、执行人员、监测人员、时间、未执行原因、未通过建单。 |
| 测评报告 | 全部轮次闭环情况、历轮汇总、需求符合情况、遗留问题登记、结论叙述。 |
| 问题单合集 | 问题字段、处理意见、影响域、回归结果、签字和时间。 |

预检结果按文档章节聚合，每项提供跳转入口。可警告项允许继续生成，阻断项必须补齐。

## Word 渲染约束

- 模板底座来自 `knowledge-base/` 真实 DOCX，不重画样式。
- 富文本从受限 Tiptap JSON 直接映射 OOXML，不做 HTML 转换主链路。
- 图片通过附件存储路径读取，写入 DOCX media 并维护关系文件。
- 表格列、合并单元格、题注和编号由模板槽位配置驱动。
- 固定话术、单源段落和数据资源引用必须登记，不允许散落在代码字符串中。
- 连续网格表、区带表、跨页表头、横页和签署页必须由内置积木或表格带区模型表达。
- 模板中的明显文字错误可通过槽位映射修正，但必须记录“模板原文 / 生成口径”的差异，便于追溯。
- 大规模记录按真实交付样本压力场景设计：354 个用例、199 张图片、1409 行大表和约 156 页文档必须可生成。
- OOXML 生成使用流式写入和临时文件原子替换，图片和大表不得一次性载入内存。
