# 页面结构、树与筛选

> 本文解决什么问题：测试项页面的整体布局、左树规则、搜索筛选与四种视图。上游 [02 测试项页面与交互](../02-测试项页面与交互.md)，下游 [03 用例与执行](../03-用例与执行.md)。

- 路由：项目工作区 `测试与执行 → 测试项`（沿用现有 `/projects/{code}/workspace/test-items`）。本页形态已于 2026-10-10 按静态图定稿（一张测试项表 + 子项卡片 + 用例概况卡）。
- 总原则：**一屏完成**（左树 + 右详情，不跳页），**像写 Word 表格**（表格化排版 + 单元格直接编辑），**键盘优先**，**保存无感**。

## 页面结构

```text
┌──────────────────────────────┬───────────────────────────────────────────────┐
│ 工具栏：[＋新增测试项][新建文件夹]        │  Hero：标识 + 名称 + 标签（类型/优先级/归属/轮次）│
│        [视图：树 | 矩阵 | 标注 | 覆盖]   │       + 完善度进度                              │
│ 搜索框：[名称 / 标识 / YL_ID]            │───────────────────────────────────────────────│
│ 快捷：[全部][未完善][有失败]｜[只看…]     │  吸顶分区导航：基本信息 · 测试方法 · 用例概况    │
│ 树（可拖拽宽度 380–620px）              │───────────────────────────────────────────────│
│  静态（DC SA CR CW）                    │  **一张「测试项表」（Word 表格观感）逐行装完**：  │
│  功能验证（SU IO GUI）…                 │   名称/标识 · 优先级/类型 · 追踪关系 ·           │
│                                        │   需求描述 · 测试项描述 · 测试方法（子项卡片）·   │
│                                        │   充分性要求 · 通过准则                          │
│                                        │  用例概况卡（用例列表 + 通过率 + 批量操作）       │
└──────────────────────────────┴───────────────────────────────────────────────┘
```

- 左侧树宽度可拖拽并记忆（复用需求页的拖拽把手口径，最小 380px）；1320px 以下改为纵向布局，只保留一个主滚动；1366px 常见笔记本仍保持左右分栏。
- 右侧详情 = **一张"测试项表"装完所有字段**，不再拆成多张卡片或多个 Tab；表格滚动时表头吸顶，顶部吸顶分区导航高亮当前段落，主色玻璃底。
- 用例详情同理：一张"用例表"（含步骤表）装完所有字段，见 [03](../03-用例与执行.md)。

## 树

| 项 | 规则 |
| --- | --- |
| 层级 | **按类型分组**（文档审查 / 静态分析 / 代码审查 / 代码走查 / 功能测试……，按字典输出序、静态四类天然置顶，有内容才显示；分组标题带类型代号，树行不再重复显示 SU/DC，也不显示优先级）→ 文件夹 / 测试项（混合排序）→ 用例（默认折叠） |
| 展开记忆 | 按项目记住展开状态；搜索或筛选命中的用例自动展开其父测试项 |
| 行徽章 | 只保留完成度/静态进度/用例执行状态/隐含标记；**优先级不在树里显示**（只在右侧详情 Hero 显示，2026-10-10 定稿） |
| 必填提醒 | 缺失必填项的测试项/用例：行左侧 2px 语义色条 + 行尾图标；与详情内红边、保存提示同源 |
| 新建 | 工具条"新增测试项"（按类型分组选类型，选中后折叠为摘要行；标识前缀自动带出）、"新建文件夹"（限当前类型） |
| 排序 | 文件夹与测试项同容器内拖拽排序（蓝线落点）；测试项可拖入同类型文件夹或拖回类型根目录，落点由后端 `POST /api/v1/test-items/{id}/move`（folderId + targetIndex）重排；默认新节点排末尾 |
| 右键菜单 | 文件夹 = 重命名 / 删除文件夹；测试项 = 复制新增（静态禁用）/ 重命名 / 生成用例 / 删除测试项；用例 = 重命名 / 复制新增 / 删除用例。删除类动作先弹二次确认，文件夹删除只解散容器、内部测试项回到类型根目录 |
| 行内重命名 | 右键「重命名」或选中节点按 `F2` → 行内输入框（Enter 提交 / Esc 取消 / 失焦取消），不跳弹窗 |
| 用例拖拽 | 同测试项内 = 排序；跨测试项 = 移动（标识随新测试项重排、关联关系跟随）；落点仅允许落在测试项行上（分组、文件夹、用例行都拒绝） |
| 键盘 | `↑/↓` 走行、`←/→` 收起/展开、`Enter` 选中；`F2` 重命名、`Delete` 删除（二次确认）、`Ctrl+D` 复制新增，均作用于树里获得焦点的节点 |
| 用例行反馈 | 详情「用例概况」每行两枚动作按钮（在目录中定位 / 复制用例），点名称或定位按钮 = 树里展开父项并高亮该用例；被选中的用例行整行弱绿底 + 左侧主色条 |
| 空态 | 无测试项时给引导卡："从类型开始建第一条测试项" + （后续）从大纲导入 |

## 搜索、筛选与视图

| 能力 | 规则 |
| --- | --- |
| 搜索 | 匹配测试项名称 / 标识 / 子项名称 / 用例名称 / YL_ID，150ms 防抖；命中用例保留父测试项并自动展开 |
| 漏斗 | 类型（多选，按项目实际存在类型）、完成度（全部 / 已完善 / 未完善）、用例状态（全部 / 已通过 / 未通过 / 未执行）；激活维度显示数字角标 |
| 快捷 chips | 全部 / 未完善 / 有失败，与漏斗叠加（AND） |
| 模式 | 只看测试项（隐藏用例行，测试项变叶子）/ 只看用例（平铺列表，按测试项分组，行内显示 YL_ID、名称、状态、未立单、问题单数） |
| 筛选作用 | 纯展示过滤，不动数据；问题单与关联关系不受影响 |
| 类型覆盖视图 | 24 类卡片：已选类型显示测试项数与跳转入口，未选类型要求填写"不测评说明"（大纲表 61/62 口径）；顶部统计"已选 N/24 · 测试项总数 · 未说明类型数" |
| 追溯矩阵 | 行 = 需求，列 = 来源文档 / 章节号 / 需求 / 测试项 / 用例 / 问题单 / 通过率；顶部统计条（需求总数、已关联测试项、用例总数、通过率、问题数） |
| 标注总览 | 需求正文与用例步骤 op/act 的选区高亮合一，列出来源 / 标识 / 名称 / 高亮文字 / 跳转；第一阶段不含测试项自由文本标注 |
