# Word 生成

## 路线

文档生成采用“原始 DOCX 模板 + 结构化数据 + Go 渲染 OOXML”。

## 要求

- 模板底座来自 `knowledge-base/` 中的真实交付文档。
- 保留封面、页眉页脚、字体、表格样式和编号格式。
- 业务数据存放在 SQLite 中。
- Go 根据受限的报告文档模型渲染字段、章节和表格行。
- Go 根据受限的文档数据模型和 Tiptap JSON 内容块渲染字段、章节、表格行和图片。
- 支持多被测系统和多类报告。
- 七类知识库模板与业务数据映射见《17-七类文档数据映射》。
- 模板大纲、数据资源字典、内置渲染积木、复杂表格带区、叙述占位和导入比对是生成灵活性的六个基础能力。

## 不采用

不采用通用 HTML 转 OOXML 作为主方案。HTML 可用于页面预览，但不是 Word 生成的中间格式。
