# 测试项与执行

> 返回 [需求索引](README.md)

测试项是项目主链路（需求 → **测试项** → 用例 → 执行 → 问题单 → 文档）的关键环：它是测评大纲 6.2 节的载体、测试说明与测试记录的骨架，也是"这一轮测什么"的答案。本主题覆盖测试项与用例的录入、静态测试项（DC/SA/CR/CW）流程、执行记录与轮次范围的衔接。

## 范围

- 测试项页：左树 + 右详情（Word 表格观感），树为“类型分组 → 文件夹 / 测试项 → 用例”，含搜索、筛选、类型覆盖 / 追溯 / 标注视图。
- 测试项字段、子项、用例 / 步骤、执行三态、需求关联、轮次复制。
- 静态测试项 DC/SA/CR/CW：专属工作台、审查单模板管理、默认通过、证据与问题单。
- 不在本主题：Word 文档生成取数、时间锚点推导、DOCX 大纲批量导入；见 [08](08-Word生成.md) 与 [17](17-七类文档数据映射.md)。
