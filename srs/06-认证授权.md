# 认证授权

## 目标

提供本地登录能力，并为后续多用户、多角色和大量 API 授权预留结构。

## 认证

- 密码使用 bcrypt 哈希。
- 登录成功后签发 JWT。
- JWT 包含用户 ID、用户名、角色、签发时间和过期时间。
- JWT 密钥保存在本地 SQLite 设置表中，首次启动自动生成。
- 令牌有效期限默认 8 小时。

## 授权

- 使用 Casbin RBAC。
- 请求维度：角色、路径、HTTP 方法。
- API 中间件统一执行认证和授权。
- 登录、健康检查、OpenAPI 文档为公开接口。
- 未登录返回 401，未授权返回 403。

## 初始账号

- 首次启动自动创建管理员。
- 默认用户名：`admin`
- 默认密码：`admin123`
- 用户名和密码可通过环境变量 `CHENMERIDIAN_ADMIN_USERNAME`、`CHENMERIDIAN_ADMIN_PASSWORD` 覆盖。
- 后续提供修改密码和用户管理功能。
