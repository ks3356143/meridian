# 跨会话记忆

本文件是跨会话记忆的固定入口。每次会话开工先读本文，再按需读取对应主题 SRS；历史会话流水已清理，只保留当前事实、约束和下一步目标。

## 当前状态

1. 项目 Go 版本为 1.27.1，本机 Go 发行包已恢复干净，直接 `go build` 可用。
2. 需求与追踪页采用左侧目录、可拖拽把手和右侧 hero + 详情结构；刷新后目录默认 380px、最大 680px，1100px 以下改为纵向布局且只保留工作区路由一个主滚动。左侧树为“来源文档 -> 已确认需求”两级，需求与测试项保持多对多契约。
3. 手动录入支持章节号、标识、名称、主类型、副类型、描述和标签；副类型不能与主类型重复。详情失焦自动保存，新增弹窗按选中需求预填同级章节号并校验同来源有效章节冲突；支持“保存并沿用”、详情复制新增和树节点右键复制新增；`Ctrl+Enter` / `Meta+Enter` 可连续提交，快捷键说明使用独立 Dialog。
4. 同版本有效需求的名称和非空标识唯一；标识留空按名称拼音首字母生成四位。后端保留 DOCX 解析、候选确认和批量入库链路。
5. 已确认需求删除使用 `official -> excluded`，删除原因可选并保留审计；统计卡可管理已删除需求，支持恢复、复制新增、查看审计、单条彻底删除、勾选批量删除和删除全部。恢复仅限最新删除来源为 `official` 的记录；彻底删除必填原因，需求与审计事件按外键级联物理删除，“删除全部”只处理可彻底删除的已删除确认需求。
6. 已确认需求支持树内批量编辑和批量删除：跨来源版本勾选、浮动操作栏、单弹窗同时修改主/副类型并按精确子串大小写敏感替换名称或标识；预览先行展示 diff 与同版本唯一性冲突，提交走事务与 `update` 审计。批量删除复用 `exclude` 状态迁移，使用二次确认、可选原因和逐条审计，不执行物理删除。
7. 需求树由 `react-arborist` 负责状态、键盘和虚拟滚动，GSAP Flip 负责展开收缩；脚本通过 `data-tree-row` 定位行。展开时先移动存量行、再淡入新增行，收缩时先淡出子树并同帧 Flip，避免重叠和首帧跳位；`prefers-reduced-motion` 下直接切换。外部选中通过 `setSelection` 同步；点击已可见行用自定义 `renderRow` 跳过库内二次滚动，键盘导航保留自动定位。批量勾选状态通过行级 Context 传递，保持行渲染函数身份稳定。
8. 全局 Textarea 使用 `react-textarea-autosize`，无拖拽手柄并按内容增高；组件自定义视觉使用同目录 CSS Module。Tailwind v4 utilities 属于独立 layer，不能依赖未分层 Module 让位给外部工具类。
9. 首页桌面侧栏断点为 900px；菜单 hover 和点击只改变颜色、背景与阴影，不产生位移或图标缩放；active 菜单无波纹，非 active 保留波纹。副类型触发器左侧显示选中标签，右侧固定单一下拉箭头。共享 Table 统一提供 1px 外框和轻阴影。
10. `R2657` 用于手动回归，保留 `§4.3.2.1 BCD星指令参数管理` 与 `§4.4 指令准确率性能`；未获明确要求不得重新解析或写入测试数据。
11. `knowledge-base/接收文件/` 是用户真实资料，禁止提交、移动或删除。
12. 长主题文档采用“入口 + 子页”：`07-前端体验`、`17-七类文档数据映射`、`20-大工作区架构落地`、`22-需求录入与解析` 和 `docs/项目记忆.md` 已拆分；后续新增细节写入对应子页，并保持双向链接。
