# 项目创建与基础字典

## 定位

项目是全部测评流程的最基点。测试大纲、测试项、用例、执行记录、问题单和报告都必须挂接到具体项目下。本轮先实现真实项目创建与基础字典，不实现文档模板选择、大纲编辑和 Word 渲染。

## 新建项目表单

表单参考团队工具 `project-new.html` 的信息组织方式，分为基本信息、技术字典、依据标准、项目人员四段。

### 基本信息

- 项目标识：前缀 `R` 固定展示，用户仅输入后四位数字；保存后完整标识为 `RXXXX`，要求全局唯一。
- 项目名称：必填。
- 研制单位：必填。
- 测评性质：`鉴定测评` / `第三方测评` / `二方测评`，单选；该字段影响后续文档措辞与数据渲染方式。
- 测试平台：`FPGA` / `CPU/非嵌`，单选；该字段影响后续模板选择、测试项默认内容和数据渲染方式。
- 软件类型：`新研` / `改造` / `沿用`，单选。
- 密级：`公开` / `内部` / `秘密` / `机密` / `绝密`，单选；该字段影响生成 Word 文档首页的密级展示。
- 安全等级：`关键A` / `重要B` / `一般C` / `不重要D`，单选；该字段影响后续测试项必备类型和大纲测试策略章节。
- 项目状态初始值固定为 `编制大纲中`。
- 用例与问题统计快照初始值为 0，后续由测试流程模块更新。

### 技术字典

以下字段均为多选，选项来自字典：

- 编程语言。
- 运行环境。
- 开发环境。

要求：

- 三类字典预置基础数据，字典数据独立维护，不与项目数据强关联。
- 新建项目页支持自定义新值。
- 自定义值必须随项目创建保存并写入对应字典，之后可复用。
- 自定义动作与项目创建放在同一后端事务中，项目创建失败时不得污染字典。
- 同一字典内按展示名去重，忽略首尾空白。

### 依据标准

### 字典管理

管理入口为 `/settings/dictionaries`，包含技术字典和依据标准两个页签。

- 技术字典支持新增、编辑、启用/停用和排序；字典类型、展示名、排序和启用状态可修改。
- 依据标准支持新增、编辑、启用/停用和排序；文档名称、标识/版本、发布日期、来源单位、排序和启用状态可修改。
- 管理接口写操作仅 admin 角色可用。
- 字典项和依据标准不提供物理删除；未被引用的自定义项也统一使用停用，保证操作可逆并保留历史痕迹。
- 预置项与自定义项均可编辑和停用，但均不可删除。
- 停用后不再出现在新建项目选项中，已创建项目的历史关联保持不变。
- 同一技术字典类别内展示名忽略大小写去重；依据标准文档名称忽略大小写去重。

依据标准采用独立字典，参考团队工具 `admin-reference-docs.html`。

字段：

- 文档名称：必填，例如 `GJB 438C-2021`。
- 标识 / 版本：例如 `GJB 438C-2021`。
- 发布日期：例如 `2022-03-01`。
- 来源单位：例如 `中央军委装备发展部`。
- 排序值。
- 启用状态。

新建项目时从启用状态的依据标准字典中多选；后续生成测评大纲时按排序渲染到依据文件章节。本轮只做选择与保存，不做标准管理页面和 Word 渲染。

### 项目人员

- 项目负责人：必填，单选，来源于系统用户表。
- 项目成员：多选，来源于系统用户表，支持按用户名或显示名搜索。
- 负责人自动具备项目成员身份。
- 同一用户在同一项目中只能有一条成员记录。
- 本轮成员仅保存归属关系，不做项目内角色和权限细分。

## 数据模型约定

### projects

保存项目基础字段、负责人、状态和统计快照。核心唯一约束：

- 完整项目标识 `RXXXX` 唯一。
- 项目名称不作为唯一键，允许同名，但列表必须始终同时展示标识和名称。

### 基础字典

- `dictionary_items`：保存编程语言、运行环境、开发环境三类通用字典。
- 字段包含字典类型、展示名、排序、启用状态、是否预置。
- 业务项目通过关联表保存选中项，避免在项目行中存 JSON 导致无法约束和统计。

### reference_standards

独立保存依据标准字典，不复用通用字典表，因为其字段比普通字典丰富。

### 关联表

- 项目编程语言关联。
- 项目运行环境关联。
- 项目开发环境关联。
- 项目依据标准关联。
- 项目成员关联。

所有业务主键使用 UUIDv7 字符串，所有表保留 `created_at`、`updated_at`。

## API 口径

- `GET /api/v1/project-options`：返回启用技术字典、启用依据标准和可分配用户。
- `POST /api/v1/projects`：一次性保存项目基础信息、字典选中项、自定义字典项、依据标准和成员。
- `GET /api/v1/projects`：返回项目列表聚合结构。
- `GET /api/v1/projects/{code}`：按 `RXXXX` 返回项目详情。
- 创建成功后进入该项目工作台。

## 本轮明确不做

- 不选择、不绑定文档模板。
- 不生成或渲染 Word。
- 不创建测评大纲草稿。
- 不实现项目编辑、删除、归档。
- 不实现项目成员角色权限。

- 字典配置流程：继续优化技术字典与依据标准的新增、编辑、启停、排序和保存后选中态反馈。
