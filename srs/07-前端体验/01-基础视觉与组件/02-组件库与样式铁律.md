# 组件库与样式铁律

> 返回 [基础视觉与组件](../01-基础视觉与组件.md)

## 组件库铁律

### 动画组件铁律

1. 交互组件的展开、收起、进出场与状态动画，一律使用 `@animate-ui/react/primitives/radix-ui/*` 提供的动画原语；`components/ui/*` 只做外观与业务包装。
2. 禁止在业务组件里手写 `@keyframes` 复刻弹窗、下拉、菜单、折叠、标签、勾选、开关、单选和进度动画；纯装饰性的品牌循环除外。
3. 动效优先级：Animate UI → Motion（参考 Motion UI 设计，用免费 API 落地）→ 网上/OpenDesign 参考 → GSAP 兜底；GSAP 仅用于几何测量、时间轴编排与品牌持续视觉。完整边界见 [动效原则与验收](../03-品牌与动效/01-动效原则与验收.md)。

### CSS Module 铁律

1. 组件自定义样式必须与组件同目录同名：`Button.tsx` 对应 `Button.module.css`，组件内 `import styles from './Button.module.css'`，自定义 `className` 使用 `styles.xxx`。
2. 变体使用 `styles.primary` / `styles.ghost` 等语义类；状态使用 `data-state`、`data-invalid`、`data-selected` 等 data 属性和 CSS 属性选择器，不在 JS 中拼接表现类。
3. Tailwind 仅保留少量布局工具和 shadcn/Radix 既有组合；业务视觉、主题变体、动画、状态和密集选择器必须进入 CSS Module。
4. CSS Module 选择器和导出名使用 camelCase；第三方子元素通过 `:global([data-slot='...'])` 定位，不用标签选择器扩大影响面。
5. 新增或改造组件时必须同步迁移该组件既有自定义全局样式；同一业务域允许按布局、树、表单、弹窗拆分多个同名组件 Module，禁止继续增长全局大 CSS。

## 性能与加载态铁律

性能优先、加载态兜底与验收环境的硬性铁律见 [21-前端性能优化策略](../../21-前端性能优化策略.md)；乐观交互契约见 [23-数据加载与渲染性能](../../23-数据加载与渲染性能.md)，本文不重复。

树导线偏移由 `data-guide-level` CSS 属性选择器定义，不在组件中写 inline style；基础 `Button`、`ContextMenu`、`Textarea` 与需求与追踪页各组件均按同目录同名 `.module.css` 管理变体与状态。

- 接收文件录入页的布局、上传进度层与工具栏选择规则已归位到 [14 接收文件与版本](../../14-项目工作区与前端模块/03-接收文件与版本.md)，本文不再保留业务细则。
- 前端设计、改版和视觉问题处理必须先读取并使用全局 `~/.claude/skills` 中匹配场景的技能：数据密集界面优先 `ui-ux-pro-max`、`shadcn`、`tailwind-4-docs`；动效优先 GSAP、Motion 与 Animate UI 相关技能；仅营销页、作品集或探索性视觉才考虑 `design-taste-frontend` 等风格技能。实现仍以当前主题、组件体系和本文件铁律为准。
- 前端卡顿、输入长任务、滚动掉帧、切换慢和拖动假死必须先按《21-前端性能优化策略》定位与验收；不允许只凭感觉删除视觉层或引入新依赖。
- 每次修改页面、组件、样式、交互或动效前，必须横向检查同类型页面和组件，并先划分影响域：全局基础组件、业务组件、单页面或全局主题。凡属于同类结构的能力必须保持整体结构一致，不能只修当前反馈页面或留下同类页面不一致。
- Select 打开和关闭过渡期间页面纵向滚动条必须保持可见，布局宽度不得变化。
- 标签使用 shadcn/Radix Badge 体系，不同语义变体保持一致尺寸；不得通过外扩阴影制造视觉高度差。
- 能使用成熟组件库的交互组件必须使用组件库：优先 shadcn/ui 与 Radix UI；表格、路由、数据使用 TanStack、React Router 等专业组件库。仅纯展示、布局或确无组件库能力时允许手写，但必须补齐无障碍、键盘操作、焦点态和微动效。
- 新增交互组件前先检查 `web/src/components/ui` 是否已有对应组件。
- 数据表格统一基于 TanStack Table 与 `DataTable` 封装，排序、空态、选中态、行键盘操作不得在业务页重复手写。
- 查询加载态统一使用 Skeleton 与 `QueryLoading`，错误态统一使用 Alert 与 `QueryError`，禁止裸文本居中充当状态页。
- 表单内多选统一使用 `Popover + Command + Badge` 组合的 `MultiSelectCombobox`，必须提供搜索、已选徽标、键盘选择和错误态。
- 多选已选徽标选入时必须有轻量插入动画，移除时先做压缩淡出再卸载；动画只使用 transform/opacity。
- 启用/停用等二元设置使用 Radix Switch；Checkbox 仅用于批量选择或明确的多选项语义。
- 移动端抽屉导航使用 shadcn Sheet，不使用居中 Dialog 模拟侧边栏。
- 图标按钮和图标型触发器需要 Tooltip 或明确的 `aria-label`。
- 提供自研快捷键的高频作业面必须在工具栏提供快捷键说明入口：图标按钮带 Tooltip，点击打开 Radix Dialog；说明按“快捷键”和“功能说明”分组，快捷键使用键帽、适用范围和结果三列表达，功能说明解释对应业务行为。弹窗支持键盘导航和 Esc 关闭，窄屏仅允许说明表横向滚动。
- 分节标题统一使用 `web/src/components/ui/section-title.tsx` 的 `SectionTitle`：主色竖线 + 0.82rem/720 字重，`size="lg"` 用于面板主标题，竖线颜色可用 `--section-tone` 覆盖（工作区模块卡片按 `--module-tone` 继承）；竖线含 0.04em 光学修正，业务模块不得再手写 `::before` 竖线或自定字号。适用范围：工作区模块/面板标题、需求详情卡标题（吸顶态的颜色与竖线高度在业务 CSS 里覆盖）。

- 同一口径需要跨「只读面 / 编辑面」共用时（如正文题注与表格），抽一个共享 `.module.css` 暴露 `.surface` 容器类，两个容器各自 `import` 同一个 module 并挂上该类；禁止用 `composes` 传声明或写全局类。示例：`web/src/features/projects/components/project-workspace/requirements/body/requirement-body-content.module.css`（只读预览的 `.viewport` 与编辑器的 `.proseMirror` 都带 `.surface`）。
