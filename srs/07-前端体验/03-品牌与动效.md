# 品牌与动效

> 返回 [前端体验](../07-前端体验.md)

## 动画

- 主页面必须提供统一的入场反馈：使用页面级 `useGSAP` 作用域、专属 reveal 类、轻微上浮淡入和 stagger；数据页需等主要内容加载完成后触发，并尊重 reduced-motion。同类主页面不得出现有的有入场动画、有的没有的结构差异。
- 使用 GSAP 和 `useGSAP` 管理动画生命周期。
- 动画快速、精致，优先突出层级和状态，不得拖慢录入效率。
- 状态卡与阶段条允许使用低速渐变流动、柔光扫过和进度条微光，用于表达 active / partial / ready 状态；循环周期不短于 2.6 秒，只动画渐变位置、透明度和 transform，禁止布局属性动画。
- 独立工作区顶栏属于高频作业入口：项目身份、轮次和状态切换必须有 180-320ms 的状态过渡；顶栏底部可使用匀速细流光，但不得影响文字对比度。
- 顶栏底部流光在浅色模式也必须清晰可辨：轨道使用品牌绿到信息蓝的 2px 渐变线，流光带增加小半径辉光；暗黑模式保持白色流光。两套主题的流光节奏一致，reduced-motion 下均关闭。
- 独立工作区顶栏必须主题感知：浅色模式使用浅色玻璃、品牌绿淡渐变、左侧品牌色轨和深色文字，避免突兀的黑绿色横幅；暗黑模式使用深绿 cockpit 和白色透明度文字。顶栏内按钮、下拉框、指标胶囊和用户胶囊共享同一套顶栏表面 token，hover / focus 只增强边框、轻背景和内高光；不得复用 `primary-foreground` 作为顶栏文字色。
- 工作区一级页面只编排一次入场：顶栏与导航先到位，内容 hero 随后淡入上浮，面板最后分组进入；主区可根据当前一级 TAB 使用低饱和语义色环境光（作业台绿、资料/对象蓝、需求紫、执行绿、交付琥珀），但导航 active 态仍以品牌绿为主。首页 hero 底部执行率信号条只做一次性充能，不循环扫动；所有进入动效必须支持 reduced-motion 直切。禁止每个卡片各自漂浮、旋转或无限呼吸。
- 必须尊重 `prefers-reduced-motion`。
- 循环动画起点和终点必须在容器外不可见区域，循环重置不允许可见跳变。
- 流光类动效一律匀速。
- 可动画 transform、opacity、filter、box-shadow、color、background-color、border-color；禁止动画 width、height、top、left 等明显触发布局的属性。
- 阴影、颜色、边框等质感过渡时长 180-320ms；多层阴影的基础态和激活态保持相同层数，避免无法插值导致跳变。
- 非必要循环动画在 reduced-motion 下关闭；一次性 hover / focus 反馈可保留但去掉位移。
- 树形结构（需求目录树等）展开 / 收缩统一走 FLIP：先按旧位置渲染首帧（tween `paused: true` + `progress(0)`），等 React 提交与首帧布局结束后的双 rAF 再 `play()`，避免 GSAP 按墙钟时间吞掉 tween 早期进度导致深层级收缩"瞬间跳变"；禁止在动画完成回调里用 `flushSync` 强制提交，长任务会把动画前段整个吃掉。
- 动画期间禁止改变滚动容器的滚动条槽位：**有折叠/展开高度动画**的树、列表常驻 `scrollbar-gutter: stable`，动画期用 `overflow: hidden`（仍是滚动容器、槽位保留），不得切成 `overflow: clip`，否则行宽突变会让右侧数量徽章 / 操作区左右跳动；FLIP 只做位移，不参与宽度变化。测试项树没有行高度动画，使用默认 `auto` 槽位，无滚动条时禁止预留整条空白；以后若给它加入高度动画，再改为按真实溢出动态保留槽位。
- **动态高度面板必须有真实起始帧（2026-10-21）**：批量操作条、筛选条、批量选择栏等随状态出现/消失的面板，如果 CSS 已写 transition，却由父组件条件挂载，第一次渲染就是最终展开态，动画不会播放。需要展开/收起双向动画的面板必须常驻挂载，用外层 `display:grid` + `grid-template-rows:minmax(0,0fr) → minmax(0,1fr)`、透明度与轻位移（不超过 4px）过渡，时长 220–300ms；内层必须 `min-height:0; overflow:hidden`，收起后置 `visibility:hidden` / `pointer-events:none` / `inert`，防止隐藏控件进入 Tab 顺序。禁止简单给 `height:auto` 加 transition，也禁止用 `max-height` 猜一个固定上限。所有高度动画在 reduced-motion 下直切。

- 共享 `DataTable` 在 720px 以下给真实表格设 42rem 最小宽度，由表格自带滚动容器横向滚动；不得把标识、状态、操作等列压成逐字竖排。纵向虚拟化表格同样遵守该最小宽度，分区滚动的滚动条与工作台一致。
- 登录页在 1023px 以下把用户名、密码和主按钮提升到 44px 触控高度；移动端顶部补品牌标识，但不重复展示桌面左侧大视觉。
- 密码框提供眼睛按钮切换明文/密文，按钮 `mousedown` 阻止默认焦点转移，切换后焦点仍留在密码框；图标 150ms 淡入缩放，reduced-motion 直切。
- 新建项目页的底部校验/提交栏在桌面可 sticky 常驻；640px 以下改为文档流静态位置，禁止用 100+px 的操作条遮挡移动端表单字段。
- `PageHeader` 必须用 `overflow: clip; overflow-clip-margin: 6px` 同时满足两件事：背景光晕不得扩大文档滚动宽度，主操作 2px outline + 2px offset 不得被裁掉。320 / 375 / 768 / 1366 / 1920 宽度均按文档根节点无横向溢验收。
- ≤430px 的 TabsList 放不下时由自身横向滚动，不得把单个 Trigger 推出文档根节点；字典配置三个页签已按此处理。
- 默认带交互反馈（2026-10-10 用户明确要求）：新页面 / 新组件默认必须带动效，至少覆盖区块与详情切换、编辑态进入、保存成功、校验失败、展开收起；没有动效的成品视为未完成。
- 华丽但不卡断：动画只碰 transform / opacity / box-shadow / color / background-color；单次 180-320ms、循环不短于 2.4s；同一屏同时动画不超过三处，reduced-motion 一律直切。
- **荧光呼吸（glow pulse）是首选状态语言**（2026-10-10 用户明确表示最喜欢这个效果，要求以后多用）：`box-shadow` 内外光晕在 2.2–2.6s 之间呼吸，颜色跟语义色走（未完善=琥珀、保存中/进行中=信息蓝、失败=红、就绪=品牌绿），**只动光晕，不动位移与尺寸**；用法是"状态容器 + 其状态芯片"成对呼吸，同一屏最多两个呼吸焦点；静止态（已保存、已完成）不呼吸；reduced-motion 一律关闭。已落地：详情完善度框（未完善）、树上"未完善"徽章、保存状态芯片的待保存/保存中/保存失败三态。
- 编辑态与展示态共用盒模型：点击进入编辑不得改变行高、列宽或容器滚动位置（2026-10-10 反馈：单元格编辑导致表格上抬属缺陷）。
- 表格内联编辑器（Word 观感表格的单元格）必须单独统一焦点：全局 `field-state.css` 给 `[data-slot="input"]` / `[data-slot="select-trigger"]` 的焦点环带 `!important`，而 `[data-slot="textarea"]` 不在其中——同一表格里单行与多行编辑器会看起来不一样；在 CSS Module 里用更高优先级 + `!important` 覆盖成同一套即可（2026-10-10 坑）：1px 边框变主色 + 3px / 12% 柔光，只过渡 border-color 与 box-shadow 且前后阴影层数一致；禁止共享组件的 3px 粗环 + 多层辉光叠加，也不允许双层环（容器环 + 输入框环）同时出现。
- 滚动容器的动效边界：详情/列表切换动画只作用于滚动容器里的内容，禁止对滚动容器本身做位移；滚动容器常驻 `scrollbar-gutter: stable`，避免滚动条出现/消失导致内容横向跳动。切换实体时用 `useLayoutEffect` 先把 `scrollTop` 归零再绘制。
- 编辑态与展示态必须逐像素同盒模型（含 1px 边框与行高），多行单元格进入编辑时用展示态实测高度作为编辑框最小高度。
## 品牌视觉

品牌视觉以“经线”（Meridian）为核心意象：经线球体线框、匀速流光、信号传递流程条构成统一动效语言。

- 品牌图标：`web/src/components/brand/logo.tsx` 的 BrandLogo（currentColor），登录页左上角、侧边栏、favicon 同源。
- favicon：`web/public/favicon.svg` + `favicon.ico`，`index.html` 先 SVG 后 ICO。
- 炫彩渐变只用于 `ChenMeridian` 品牌字标和品牌装饰，不扩散到正文、页面功能标题和控件。
- `brand-wordmark` 用于侧边栏与移动抽屉：炫彩渐变文字，12 秒慢速流动；reduced-motion 下保留静态渐变。
- 登录页大字标：逐字符炫彩渐变、stagger 上浮入场、14 秒 hue-rotate 慢转。
- 登录页经线流光：字标下方 1px 线上一条辉光光带匀速滑过，5.2 秒一轮，间隔 0.5 秒。
- 登录页流程信号传递：测试项 -> 用例 -> 执行 -> 报告使用 lucide 图标节点与连续进度轨；信号点匀速推进，按 active / completed 状态点亮，循环结束前整体淡出。
- 流程轨首尾节点必须贴齐同一段落的左右边界。
- 流程轨节点必须等距分布：相邻节点中心间距一致（网格用等宽列 + space-between 实现，禁止首尾定宽列加中间 1fr 列造成两端短中间长的间距）；信号点推进的等分时间必须与节点等距位置对齐，信号点到达节点时刻即该节点激活时刻。
- 登录页背景光斑：两个 primary 径向光斑 4.8 秒呼吸。
- 登录页右上角经线球线框：嵌套椭圆 SVG，70 秒匀速旋转。
- 登录按钮：hover 白色光泽扫过（`btn-sheen`，0.7 秒 cubic-bezier）。
- 重要功能按钮：统一使用共享 `<Button sheen>` 光泽扫过（110° 白色高光，0.58 秒 cubic-bezier，hover / focus-visible 触发）；禁止在业务组件里重复写伪元素和渐变。`prefers-reduced-motion` 下关闭扫光。登录按钮的 `btn-sheen` 为历史实现，后续触碰登录页时迁移到 `sheen`。
- 工作台标题保持黑色粗体；标题下方可保留匀速流光线，指标条 stagger 入场，数字从 0 滚动到目标值。

## HUD 四角瞄准框（2026-10-19 用户确认喜欢）

- **定位**：只用于“当前可编辑目标”的聚焦强调，属于用户点名喜欢的特效，后续可优先考虑；不是常态边框，也不替代 `focus-visible`。
- **形态**：直角 HUD 四角短刻线，角长 4–6px、线宽 1px，角标落在外框内/外沿 2–3px；无圆角、无箭头、无扫描线。使用品牌主色；错误态切语义错误色，保存/完成态只保留现有脉冲，不叠加角标动画。
- **动画**：进入 140–180ms，透明度 0→1 + 轻微 scale 0.96→1；退出 120–150ms 淡出；不循环、不位移、不改变尺寸/布局，`prefers-reduced-motion` 直接显示/隐藏。
- **使用范围**：同一时刻只标记一个编辑单元；适合即时输入框、富文本单元格、当前表格单元格。不要用于普通 hover、静态卡片、全站按钮或列表行。
- **窄字段**：输入框宽度不足时缩短角长，或只保留上下两角，避免四角挤在一起。
- **实现建议**：优先 CSS Module + 伪元素/四个轻量 span，几何和颜色用局部变量；不改全局 `::selection` 或通用输入边框；角标挂在编辑器外框，不跟随内部滚动。
- **验收**：浅色/暗色、鼠标/键盘、正常/错误、单行/多行、375px 宽度均需检查；视觉结论用截图，不以 DOM 断言代替。

## 首屏启动动画

白屏期是应用给用户的第一印象：Vite 冷启动需要按需编译模块，React 挂载前 `#root` 只有空白 DOM，必须用预挂载首屏把"编译 / 加载中"翻译成"正在校准经线"的品牌仪式感。

- 设计读法：全屏唯一焦点层，居中纵向排列：经线球线框（外圈轨道 9 秒匀速旋转）-> `ChenMeridian` 炫彩字标（12 秒慢速流动）-> 2px 经线轨道流光（5.2 秒一轮，与登录页流光同节奏）-> 弱色状态文字"正在校准经线"。
- 信息密度：零业务信息；不显示版本号、后端状态等可变内容，只保留固定品牌文案，避免加载期间状态跳变。
- 语义色：背景跟随主题（浅色 `oklch(0.975 0.005 125)`，暗色 `oklch(0.165 0.012 150)`），球体与流光使用 primary，字标使用全局 wordmark 渐变，状态文字为 primary 与背景的中低强度混合；允许一层 primary 低强度径向光晕（透明度不超过 10%）制造层次，不引入新语义色。
- 组件库选型：预挂载首屏必须零 JS 依赖，内联在 `index.html` 用纯 CSS 实现（React 组件在模块编译完成前无法渲染，无法覆盖白屏期）；React 挂载后的路由加载态使用本地 `ShinyText`（CSS 光泽扫过文字）+ 品牌 wordmark + 经线球组合，不再使用骨架屏充当路由加载态。数据查询加载态仍统一使用 Skeleton。
- 交互状态：首屏不可交互、不遮挡后续内容；React 挂载后整层自然替换，不做退场动画（退场动画会推迟可交互时间）。
- 暗色模式：`index.html` 头部预置极小脚本读取 next-themes 存储键 `theme`，首帧前把 `dark` class 挂到 `html`；暗色用户首屏直接进入深色背景，消除主题闪白。
- 响应式断点：320px 最窄视口字标不溢出不换行（clamp 字号），球体 48-64px 自适应，流光轨道 `min(15rem, 60vw)`；内容全部居中。
- 动效时长：球体轨道 9s/圈匀速、字标渐变 12s、流光 5.2s/轮匀速、状态文字光泽 2.4s 扫过；只动画 transform、background-position，禁止布局属性动画；循环起点终点都在容器外不可见区域。
- reduced-motion：首屏全部动效关闭，保留静态渐变、静态球体和 2px 静态轨道；ShinyText 通过 CSS `prefers-reduced-motion` 关闭光泽动画。
- 移动端表现：布局与桌面一致，仅缩小间距和球体尺寸；不使用 WebGL 等高开销渲染，避免低端设备首屏更卡。
- 美化口径：首屏元素间距 16-24px 呼吸，光晕只作为背景层次；严禁在首屏堆卡片、按钮或营销文案。

## 文字光学居中口径（2026-10-10 定稿）

小尺寸控件（按钮 / 徽章 / TAG / 输入框）里的中文常被看成“靠上”，实测根因是 CJK 字形墨迹的视觉重心比行盒中心高约 0.3–0.5px（字号越小越明显），不是布局写错。

- 补偿方式：文字容器的**顶部 +1px、底部等量 -1px**（总高不变），文字整体下移 0.5px；固定高度容器（`height: 0.95rem` 这类）直接“顶部 +1px、底部 0”。
- 图标与文字成对出现时先对齐两者：`Button` 的 `svg { margin-bottom: var(--btn-icon-shift, 2px) }`（图标比文字低 0.5px 时两者墨迹中心重合）；纯图标尺寸把 `--btn-text-shift` / `--btn-icon-shift` 都置 0。
- 验收口径：按“墨迹盒”判，不按 `line-height` 盒判——截图后逐行统计与背景对比度 > 45 的像素数，比较首行上留白与末行下留白，目标 |gapTop − gapBot| ≤ 0.5px。
- 反例：用 `@font-face` + `ascent-override` 归一中文度量本可一次修好，但应用内浏览器不解析 `local()` 字体源，无法验证，已放弃；不要再走这条路线（见 `docs/项目记忆/前端视觉与交互.md`）。

## 全站动效补齐（2026-10-22）

### 路由 · 页面 · Tab

- 普通业务路由进入统一 240ms 透明度淡入（起始 0.78），工作区一级 TAB 内容切换同样只做透明度入场、不做纵向位移；由布局层统一承担，业务页不得各自重复整页淡入。路由切换不使用原生 root View Transition——旧页快照会把文档滚动条一起淡入，侧栏、顶栏与滚动条必须保持稳定。
- 共享 `TabsContent` 的 active 内容进入 160–200ms 透明度淡入；默认 Tab 增加 2px 主色活动下划线，沿用 line variant 的 scale 过渡，禁止切换时改变内容高度。
- 共享 `TabsContent` 作为 Radix 可聚焦面板必须提供 `:focus-visible` 内描边（`--ring` 半透明 + `outline-offset:-2px`），不得只写 `outline-none` 让键盘用户丢失焦点位置。
- 工作区一级导航活动态 = 2px `::after` 下划线 + `::before` 表面扫光，不得共用伪元素；`::before` 必须显式 `position:absolute; inset:0; display:block`。下划线基层保持纯主色，叠一层白色窄高光做 560ms 单次扫过 + 低强度光晕，结束移出可见区、终态均匀；禁止再用 active 态 inset box-shadow 叠第二条粗线。
- `PageHeader` 的经线底轨单次扫过（约 1.25s，`animation-iteration-count:1`），只动 transform / opacity，结束移出可见区；`prefers-reduced-motion` 下关闭，业务页不再用 GSAP 重复驱动同一条底轨。
- 工作区一级导航在 hover / keyboard focus 时预加载目标页面模块，点击只负责挂载；预加载不得提前请求业务数据。低倍 CPU 下模块切换不得出现 long task，4x CPU 允许首载一次短任务，但必须保留 `QueryLoading` 反馈。

### 控件与状态

- 高频小控件只做短促状态反馈：Checkbox / Radio 勾选标记 150ms `fade + zoom`，主题按钮图标 150ms 交叉淡入；均只动 transform / opacity，reduced-motion 直切终态。
- 语义徽章和 active Tab 文字使用 `*-ink` 前景 token（警告用更深警告墨色），不在浅色底上直接用原语义色；浅色主色为 `oklch(0.535 0.15 153)`，保证白字主按钮与 12–14px 标签可读。
- 共享主按钮（`variant="default"`）**不带前侧竖条**：2026-10-22 用户明确否决——图标按钮前面多一条浅色轨会看成“不是正方形”，富文本状态按钮也会歪。只保留顶部 1px 高光 + hover / focus-visible 单次 580ms 斜向纸面高光；高光依赖 `isolation:isolate` + `z-index:-1` 才能画在自身底色之上、文字之下。
- 纯图标按钮必须正方形：`size=icon*` 已有固定宽高；“文字收起后变图标”的按钮必须在同一断点把宽度对齐高度（需求树 `width:2rem` 对齐 `size=sm`），工具栏用 `min-width:1.75rem; padding-inline:0` 对齐 `size=xs`。验收直接量 `getBoundingClientRect()`，宽高差 < 1px 才算方形。
- 输入类控件（Input / Select / 复合输入 / Textarea）的焦点与错误视觉唯一事实源是 `web/src/styles/field-state.css`：焦点 = 1px 内嵌主色描边 + 2px 外环 + 低强度光晕，错误态换 `--destructive` 并带一次性入场与低频脉冲。禁止在组件里用 Tailwind `shadow-[]` 叠加（layer 优先级更低，是死代码）；所有轨道用 `box-shadow`，不得改 padding 或高度。
- 圆角统一 0–2px：AlertDialog / Field 组合容器 / Dialog 用 `rounded-sm`，Checkbox 2px，`SectionTitle` 等活动竖线为 0；不得残留 `999px` 胶囊线。
- 全站交互态 `transition` 缓动统一 `var(--ease-out-strong)`；除循环呼吸、骨架扫光等按语义保留的 `ease-in-out` / `ease-out`，不再散落浏览器默认 `ease`。新增组件复用现有 motion token，不单独发明近似曲线。

### 布局 · 滚动 · 性能

- 静态测试项的完善度卡只有一行说明时，容器必须 `height:auto` 随内容收紧（`data-state="static"`）；未完善 / 已完善状态才用固定高度对齐缺口 chip。
- 悬浮展开按钮保持固定盒宽，用 `clip-path` 显露左右范围，图标和文字只用 transform / opacity；禁止 transition `width / max-width / padding / gap`。
- 非虚拟化 `DataTable` 行首次挂载允许 180ms 透明度 + 3px 上浮入场，按行号最多错峰 144ms；虚拟化表格关闭行入场。
- 共享 `Skeleton` 使用低对比扫光（周期 1.8s）；`EmptyHint` 首次出现 180ms 透明度 + 3px 上浮；两者 reduced-motion 直切。
- 需求详情“创建测试项”悬浮按钮以真实主按钮为滚动阈值，不用固定高度透明哨兵：动态查找最近可滚动祖先，滚动 / resize 用 rAF 合并读取位置，只有主按钮滚出上方才显示；≤1100px 固定到视口右下，`body` 保持 `min-width:0`，移动端只做 `overflow-x:clip`。验收覆盖桌面 body 内滚动、320px、滚回顶部隐藏与 reduced-motion 直切。
- 侧栏主导航 active 左侧轨必须满行高：`::before { inset-block:0; left:0; width:2px }`，只让 `scaleY` / `opacity` 进出；禁止上下内缩，禁止用 inset box-shadow 另叠一条。需求树、测试项树等行级活动轨同样满行高。
- 共享 `Table` 内层 `table-container` 只承担横向滚动，必须显式 `overflow-y:hidden`：行入场 `translateY(3px)` 会让纵向溢出回落为 `auto`，闪出 18px 滚动条并挤窄表格。

## 已确认设计理念（2026-10-22）

- **稳定优先于戏剧性**：炫酷只通过光、色、层次和短促高光表达，不能以页面位移、滚动条闪现、宽度抖动或布局跳变为代价。
- **活动指示器必须贴合元素边界**：左侧活动轨默认满行高；Tab 活动线默认单条；不要把“留呼吸”做成上下悬空，也不要用多层 inset 叠粗。
- **闪光只能是一次性高光**：高光层与结构底色分离；动画结束后高光必须离开可见区，终态保持均匀、干净，不留下深色渐变块。
- **页面切换只更新内容层**：业务路由不截整页快照做交叉淡入，避免旧页滚动条、滚动位置和内容高度污染新页面；统一使用主内容透明度淡入。
- **每个滚动容器职责单一**：表格内层只负责横向滚动，不得因为行入场 transform 临时产生纵向滚动条；跨页稳定性由 `scrollbar-gutter` 和正确的 overflow 轴共同保证。
- **窄屏活动项必须完整可见**：Tab 条用 `justify-content: safe center`（Tailwind `justify-center-safe`），溢出时退回起点对齐，禁止裸 `justify-center` + `overflow-x:auto` 把首项推到负坐标；Tab 条与阶段条隐藏滚动条但保留横向拖动。active Tab 在首屏、切换和窗口宽度变化后都要完整可见：用 `ResizeObserver` 观察 Tab 条，只调整 `scrollLeft`；禁止用 `scrollIntoView`，它会连带把文档纵向滚回顶部。
