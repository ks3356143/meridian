# 全页第二轮 UI 优化（参考站对齐）

> 返回 [前端体验](../07-前端体验.md)；视觉口径见 [01/01 视觉方向](01-基础视觉与组件/01-视觉方向.md)，动效底线见 [03 品牌与动效](03-品牌与动效.md)。

## 目标与边界

- 只动前端界面层：文字可读性、可点击性、动效、布局、层级与留白；不改业务逻辑、字段口径、数据结构与后端接口。
- 全站口径：直角集中色风（品牌绿主色 + 警告/错误/强调/普及四类语义色，同一语义只用一个颜色）；相邻容器 1px 细边框或明确明度差；阴影扩散 ≤14px；hover 不位移。
- 参考顺序：知识库（`页面/ChenMeridian-直角集中色风.md`）→ OpenDesign 内置技能库（安装目录 `resources/open-design/skills`）→ 参考站（Linear / Vercel / Stripe / Notion / Arc）。只借鉴信息密度、层级、边界与状态表达，不抄色值与尺寸。
- 动效底线（必须守）：只动 transform / opacity；连续操作不打断、不排队、不遮挡可交互区；长列表/树/表格滚动稳定；键盘与鼠标同等反馈；`prefers-reduced-motion` 直切但状态仍可见；纯装饰循环不常驻。
- 参考区间只作参考：点击反馈约 100ms、常用交互 150–250ms、入场/退出 ≤300ms；曲线与形式按页面气质自定。
- 执行节奏：先在一个页面做样本，确认观感与性能后再铺开；每页改完在同一页验证，不逐页问。
- **紧凑性约束（2026-11-02 用户强调）**：工作区的「需求与追踪」「测试与执行」两个页面保持紧凑，不放大行高、列距和卡片内边距；文字可读性通过字号/对比度解决，不靠加间距。

## 每页统一检查三维度

1. **文字可读性**：对比度、字号、行高、截断、弱色文字是否过灰；数字用等宽 + `tabular-nums`。
2. **可点击性**：按钮/标签/行/静态/禁用态是否说清楚；hover 有边界与背景反馈但无位移；focus-visible 统一 2px 环。
3. **动效**：是否缺失、生硬或时机不对；优先一次性高光与状态过渡，禁止常驻装饰循环。
