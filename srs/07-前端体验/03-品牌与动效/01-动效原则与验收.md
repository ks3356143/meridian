# 动效原则与验收

> 本文解决什么问题：全站动画的硬约束、交互边界和“用起来舒服”的验收口径。上游 [03 品牌与动效](../03-品牌与动效.md)，下游按页面落地时执行。
>
> 全站动效一律完整播放，不按系统 reduced-motion 降级（用户明确要求）。

## 动效必要性

动效是基本必要项：默认必须有动效与状态反馈，讨论的是形式与强度，不是要不要做。没有动效的成品视为未完成。

## 引擎分工与优先级（2026-11-09 用户口径）

**优先级自上而下，不得跳级：**

1. **Animate UI（`@animate-ui/react`，免费开源，已装）**：有对应成熟原语的直接用——dialog、alert-dialog、sheet、drawer、popover、hover-card、tooltip、菜单系（dropdown/context/menubar）、select、tabs、accordion、collapsible、checkbox、radio-group、switch、toggle-group、slider、progress 走 `primitives/radix-ui/*`；效果层用 Fade（行、卡片、面板、徽标入场）、CountingNumber（数字滚动）、ScrollProgress（顶部阅读进度条）、HoverCard（截断文本预览）。Animate UI 已自带的 texts、carousel、cursor、scroll-progress、pinned-list 优先用 Animate UI 版本，不得重复自造。表格行、树行、面板与页面入场统一走 Fade / `useSubtleReveal`（Motion 驱动）。
2. **Motion：参考 Motion UI，用免费 API 落地**：Motion UI（motion.dev/ui，Motion+ 付费，项目无授权）只作视觉参考，禁止安装私有包、禁止复制源码；实现一律用 Motion（`motion` 包，免费 MIT，已装）免费 API，统一从 `@/lib/motion` 引入（`animate`、keyframes、stagger、`AnimatePresence`）。
3. **网上设计参考与 OpenDesign 参考**：AU 与 Motion 都不够直接时，先查知识库、网上成熟产品案例与 OpenDesign 参考，借鉴手法、节奏与交互模式；落地仍走 ①②，不得为参考方案引入新动画库或付费包。
4. **GSAP 兜底**：只有当 AU/Motion 明显不合适或成本过高时才用——按真实几何测量的位移与尺寸（工作区导航活动线、需求树逐行裁剪与结构位移 FLIP）、时间轴编排（登录页流程图循环、多段编舞）、品牌持续视觉。当前 GSAP 仅剩 login-visual、requirements-tree、project-workspace-layout 三处。

**禁止手搓：** 自写 CSS `@keyframes`、手写动画状态机属于手搓，禁止（纯装饰性的品牌循环除外）；用 Motion 免费 API 实现不算手搓。

**禁止第三套写法：** 不新增动画库；新增交互组件前先查 Animate UI 与 shadcn/ui 是否已有实现，没有才自写，并在 SRS 记录原因。

**决策边界（2026-11-08/09）：** AvatarGroup 需要 `@floating-ui/react` 可选对等依赖且当前无多头像展示场景，不引入；Sidebar 原语面向可折叠侧栏，用户已拍板侧栏不做折叠、长期固定显示，维持不替换。

**量高容器约束（2026-11-09）：** 富文本嵌入“挂载即量高”的容器（Collapsible/Accordion 等）时，子树内不得有 `content-visibility` 虚拟化占位；懒加载内容用 settled 门控——数据就绪后才展开面板，动画只播一次并直接开到真实高度。坑位见 [前端视觉与交互/02-动效与反馈](../../../docs/项目记忆/前端视觉与交互/02-动效与反馈.md)。

**Motion UI 能力对照（仅参考，不引入）：**

| Motion UI 能力 | 项目场景 | 采用方案 |
|---|---|---|
| AnimateNumber 数字滚动 | KPI 指标、统计数 | Animate UI `texts/counting-number` |
| Typewriter 打字机 | 引导文案、加载文案 | Motion 免费 API（暂无落点） |
| ScrambleText 乱码解码 | 标题、加载态 | Motion 免费 API（按需） |
| splitText 拆分字符 | 逐字入场 | Motion 免费 API 的 stagger（AU 无 split） |
| Ticker 跑马灯 | 公告、滚动条 | Motion 免费 API（AU 无跑马灯） |
| Carousel 轮播 | 轮播 | Animate UI `carousel` |
| Curtains 页面转场 | 路由切换 | Motion 免费 API（当前为路由 Fade） |
| Cursor 光标吸附 | 指针反馈 | Animate UI `cursor` |
| Gallery 3D 画廊 | 展示页 | 仅参考，不实现 |
| AnimateView 视图转场 | 视图切换 | Motion 免费 API |

**时长收口：** Animate UI 的默认时长偏长，统一在 `components/ui/*` 里显式传入：弹窗与确认框 220ms、抽屉 260ms、提示 160ms、折叠 240ms、标签面板 220ms；菜单类保留其 100ms 快速淡入 + 220ms 缩放。勾选、单选使用 0.16s、无延迟的过渡，避免每次勾选都有空等。

## reduced-motion 决策（2026-11-08，用户明确要求）

本项目明确不做 reduced-motion 降级：所有动效在任何系统设置下都一律播放。不得在 CSS 或 JS 中重新加入 `prefers-reduced-motion` 分支；组件原语通过 `AnimateUIProvider` 与 `MotionConfig` 的 `reducedMotion="never"` 统一关闭库内降级。

## 动画

- 主页面必须提供统一的入场反馈：统一走 `useSubtleReveal`（Motion 驱动，内部 Fade 语义）或 Fade 包裹，轻微淡入和 stagger；数据页需等主要内容加载完成后触发。同类主页面不得出现有的有入场动画、有的没有的结构差异。
- 动画快速、精致，优先突出层级和状态，不得拖慢录入效率。
- 状态卡与阶段条允许使用低速渐变流动、柔光扫过和进度条微光，用于表达 active / partial / ready 状态；循环周期不短于 2.6 秒，只动画渐变位置、透明度和 transform，禁止布局属性动画。
- 独立工作区顶栏属于高频作业入口：项目身份、轮次和状态切换必须有 180-320ms 的状态过渡；顶栏底部可使用匀速细流光，但不得影响文字对比度。
- 顶栏底部流光在浅色模式也必须清晰可辨：轨道使用品牌绿到信息蓝的 2px 渐变线，流光带增加小半径辉光；暗黑模式保持白色流光。两套主题的流光节奏一致。
- 独立工作区顶栏必须主题感知：浅色模式使用浅色玻璃、品牌绿淡渐变、左侧品牌色轨和深色文字，避免突兀的黑绿色横幅；暗黑模式使用深绿 cockpit 和白色透明度文字。顶栏内按钮、下拉框、指标胶囊和用户胶囊共享同一套顶栏表面 token，hover / focus 只增强边框、轻背景和内高光；不得复用 `primary-foreground` 作为顶栏文字色。
- 工作区一级页面只编排一次入场：顶栏与导航先到位，内容 hero 随后淡入上浮，面板最后分组进入；主区可根据当前一级 TAB 使用低饱和语义色环境光（作业台绿、资料/对象蓝、需求紫、执行绿、交付琥珀），但导航 active 态仍以品牌绿为主。首页 hero 底部执行率信号条只做一次性充能，不循环扫动。禁止每个卡片各自漂浮、旋转或无限呼吸。
- 循环动画起点和终点必须在容器外不可见区域，循环重置不允许可见跳变。
- 流光类动效一律匀速。
- 可动画 transform、opacity、filter、box-shadow、color、background-color、border-color；禁止动画 width、height、top、left 等明显触发布局的属性。
- 阴影、颜色、边框等质感过渡时长 180-320ms；多层阴影的基础态和激活态保持相同层数，避免无法插值导致跳变。
- 非必要循环动画不新增；一次性 hover / focus 反馈可保留但去掉位移。
- 树形结构（需求目录树等）展开 / 收缩统一走 FLIP：先按旧位置渲染首帧（tween `paused: true` + `progress(0)`），等 React 提交与首帧布局结束后的双 rAF 再 `play()`，避免 GSAP 按墙钟时间吞掉 tween 早期进度导致深层级收缩"瞬间跳变"；禁止在动画完成回调里用 `flushSync` 强制提交，长任务会把动画前段整个吃掉。
- 动画期间禁止改变滚动容器的滚动条槽位：**有折叠/展开高度动画**的树、列表常驻 `scrollbar-gutter: stable`，动画期用 `overflow: hidden`（仍是滚动容器、槽位保留），不得切成 `overflow: clip`，否则行宽突变会让右侧数量徽章 / 操作区左右跳动；FLIP 只做位移，不参与宽度变化。测试项树没有行高度动画，使用默认 `auto` 槽位，无滚动条时禁止预留整条空白；以后若给它加入高度动画，再改为按真实溢出动态保留槽位。
- **动态高度面板必须有真实起始帧（2026-10-21）**：批量操作条、筛选条、批量选择栏等随状态出现/消失的面板，如果 CSS 已写 transition，却由父组件条件挂载，第一次渲染就是最终展开态，动画不会播放。需要展开/收起双向动画的面板必须常驻挂载，用外层 `display:grid` + `grid-template-rows:minmax(0,0fr) → minmax(0,1fr)`、透明度与轻位移（不超过 4px）过渡，时长 220–300ms；内层必须 `min-height:0; overflow:hidden`，收起后置 `visibility:hidden` / `pointer-events:none` / `inert`，防止隐藏控件进入 Tab 顺序。禁止简单给 `height:auto` 加 transition，也禁止用 `max-height` 猜一个固定上限。

- 共享 `DataTable` 在 720px 以下给真实表格设 42rem 最小宽度，由表格自带滚动容器横向滚动；不得把标识、状态、操作等列压成逐字竖排。纵向虚拟化表格同样遵守该最小宽度，分区滚动的滚动条与工作台一致。
- 登录页在 1023px 以下把用户名、密码和主按钮提升到 44px 触控高度；移动端顶部补品牌标识，但不重复展示桌面左侧大视觉。
- 密码框提供眼睛按钮切换明文/密文，按钮 `mousedown` 阻止默认焦点转移，切换后焦点仍留在密码框；图标 150ms 淡入缩放。
- 新建项目页的底部校验/提交栏在桌面可 sticky 常驻；640px 以下改为文档流静态位置，禁止用 100+px 的操作条遮挡移动端表单字段。
- `PageHeader` 必须用 `overflow: clip; overflow-clip-margin: 6px` 同时满足两件事：背景光晕不得扩大文档滚动宽度，主操作 2px outline + 2px offset 不得被裁掉。320 / 375 / 768 / 1366 / 1920 宽度均按文档根节点无横向溢验收。
- ≤430px 的 TabsList 放不下时由自身横向滚动，不得把单个 Trigger 推出文档根节点；字典配置三个页签已按此处理。
- 默认带交互反馈（2026-10-10 用户明确要求）：新页面 / 新组件默认必须带动效，至少覆盖区块与详情切换、编辑态进入、保存成功、校验失败、展开收起；没有动效的成品视为未完成。
- 华丽但不卡断：动画只碰 transform / opacity / box-shadow / color / background-color；单次 180-320ms；循环动画保持现有规模，不新增同屏循环。
- **荧光呼吸（glow pulse）是首选状态语言**（2026-10-10 用户明确表示最喜欢这个效果，要求以后多用）：`box-shadow` 内外光晕在 2.2–2.6s 之间呼吸，颜色跟语义色走（未完善=琥珀、保存中/进行中=信息蓝、失败=红、就绪=品牌绿），**只动光晕，不动位移与尺寸**；用法是"状态容器 + 其状态芯片"成对呼吸，同一屏最多两个呼吸焦点；静止态（已保存、已完成）不呼吸。已落地：详情完善度框（未完善）、树上"未完善"徽章、保存状态芯片的待保存/保存中/保存失败三态。
- 编辑态与展示态共用盒模型：点击进入编辑不得改变行高、列宽或容器滚动位置（2026-10-10 反馈：单元格编辑导致表格上抬属缺陷）。
- 表格内联编辑器（Word 观感表格的单元格）必须单独统一焦点：全局 `field-state.css` 给 `[data-slot="input"]` / `[data-slot="select-trigger"]` 的焦点环带 `!important`，而 `[data-slot="textarea"]` 不在其中——同一表格里单行与多行编辑器会看起来不一样；在 CSS Module 里用更高优先级 + `!important` 覆盖成同一套即可（2026-10-10 坑）：1px 边框变主色 + 3px / 12% 柔光，只过渡 border-color 与 box-shadow 且前后阴影层数一致；禁止共享组件的 3px 粗环 + 多层辉光叠加，也不允许双层环（容器环 + 输入框环）同时出现。
- 滚动容器的动效边界：详情/列表切换动画只作用于滚动容器里的内容，禁止对滚动容器本身做位移；滚动容器常驻 `scrollbar-gutter: stable`，避免滚动条出现/消失导致内容横向跳动。切换实体时用 `useLayoutEffect` 先把 `scrollTop` 归零再绘制。
- 编辑态与展示态必须逐像素同盒模型（含 1px 边框与行高），多行单元格进入编辑时用展示态实测高度作为编辑框最小高度。

## 全站交互边界与 Hover 可见性（2026-11-01）

- 结构容器只能有一个边框所有者。父容器已经有 1px 结构边框时，子级 Trigger / Tab / 行不得再绘制整圈 `outline` 或 `inset 0 0 0 1px`，避免双层边框。
- 基础边框提高一档对比度；hover 通过 `--interactive-border`、`--interactive-surface`、`--interactive-glow` 三个语义 token 统一增强，不在各页面重复散落固定色值。
- 可点击表面的 hover 只允许背景变化、单边框换色、左侧 2px 强调线、同等层数的 box-shadow 辉光；禁止位移、缩放或字体跳变。键盘 `focus-visible` 保留 2px 可见焦点环。
- Accordion 的整行是唯一交互表面：容器维持结构边框，Trigger 不再绘制内圈边框；hover/open 使用浅主色底和左侧强调线，箭头盒提供可点击提示。
- Tabs 的列表负责结构边框，Trigger 的 hover/active 只用浅底、文字色和底部/左侧强调线，不再给 Trigger 加整圈边框。自定义容器已绘制整圈结构边框时，内嵌 `line` TabsList 必须关闭底轨 `background-image`，避免父边框与底轨形成双层底线。
- 表格容器负责外框，行 hover 只用浅色底、左侧强调线和横向辉光；排序表头不叠加按钮边框。
- DC 审查单切换禁止对整张旧表和新表做 View Transition 交叉淡化；只允许旧表面立即卸载、新表面在 200ms 内轻微淡入，不做纵向位移，确保任何时刻只有一张审查单可见，也不拖动外层滚动位置。
- 以上状态过渡时长 180–240ms；一次性 hover 反馈保留最终视觉，不做常驻呼吸动画。
- 一级导航活动线按目标宽度提交一次尺寸，过渡只动画 GSAP `x / scaleX`；目标未变化的重复测量禁止重启 tween。高频一级导航移除 active 图标弹入。

## 动效舒适度验收（2026-11-02 用户强调）

验收口径是“用起来舒服”，不是“写了动效”。分两层：**底线必须守，具体手法允许发挥。**

### 底线（不可破）

- 只动 `transform` / `opacity`；不出现布局属性动画导致的抖动。
- 连续操作不打断、不排队、不遮挡可交互区域；快速连点时动画允许被打断并接住最新状态，不能回放旧状态。
- 长列表、树、表格滚动稳定：行入场、sticky 表头、hover 都不引起内容位移或滚动条跳动。
- 键盘操作与鼠标同等反馈：方向键切换、Tab 聚焦、Enter 触发都有可见状态变化。
- 状态变化必须可见，不能变成“没反应”。
- 动效必须服务于反馈、层级或引导；纯装饰性循环动画不得常驻。

### 参考区间（可合理偏离）

- 点击到可见反馈 100ms 量级；常用交互 150–250ms；入场/退出不超过 300ms。
- 具体时长、缓动曲线、动效形式由实现者按页面气质决定；只要操作不觉得迟滞或突兀，偏离区间不算问题。

### 鼓励发挥

- 反馈方式（阴影、光晕、描边，或位移以外的替代手法）、层级表达、状态转场的形式不设固定模板。
- 有新想法先小范围做一个样本，确认观感和性能后再铺开。
