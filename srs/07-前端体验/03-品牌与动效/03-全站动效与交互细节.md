# 全站动效与交互细节

> 本文解决什么问题：HUD 四角瞄准框、路由/Tab、构造流程、控件状态、滚动与性能、快速切换和指针聚光的落地口径。上游 [03 品牌与动效](../03-品牌与动效.md)，通用约束见 [01 动效原则与验收](01-动效原则与验收.md)。

## HUD 四角瞄准框（2026-10-19 用户确认喜欢）

- **定位**：只用于“当前可编辑目标”的聚焦强调，属于用户点名喜欢的特效，后续可优先考虑；不是常态边框，也不替代 `focus-visible`。
- **形态**：直角 HUD 四角短刻线，角长 4–6px、线宽 1px，角标落在外框内/外沿 2–3px；无圆角、无箭头、无扫描线。使用品牌主色；错误态切语义错误色，保存/完成态只保留现有脉冲，不叠加角标动画。
- **动画**：进入 140–180ms，透明度 0→1 + 轻微 scale 0.96→1；退出 120–150ms 淡出；不循环、不位移、不改变尺寸/布局。
- **使用范围**：同一时刻只标记一个编辑单元；适合即时输入框、富文本单元格、当前表格单元格。不要用于普通 hover、静态卡片、全站按钮或列表行。
- **窄字段**：输入框宽度不足时缩短角长，或只保留上下两角，避免四角挤在一起。
- **实现建议**：优先 CSS Module + 伪元素/四个轻量 span，几何和颜色用局部变量；不改全局 `::selection` 或通用输入边框；角标挂在编辑器外框，不跟随内部滚动。
- **验收**：浅色/暗色、鼠标/键盘、正常/错误、单行/多行、375px 宽度均需检查；视觉结论用截图，不以 DOM 断言代替。

## 全站动效补齐（2026-10-22）

### 路由 · 页面 · Tab

- 普通业务路由进入统一 240ms 透明度淡入（起始 0.78），工作区一级 TAB 内容切换同样只做透明度入场、不做纵向位移；由布局层统一承担，业务页不得各自重复整页淡入。路由切换不使用原生 root View Transition——旧页快照会把文档滚动条一起淡入，侧栏、顶栏与滚动条必须保持稳定。
- 共享 `TabsContent` 的 active 内容进入 160–200ms 透明度淡入；默认 Tab 增加 2px 主色活动下划线，沿用 line variant 的 scale 过渡，禁止切换时改变内容高度。
- 共享 `line` TabsList 的底轨不得使用会参与布局的 `border-bottom`：它与 Trigger 的 2px `::after` 叠加时，活动线会悬在容器外底边上方约 1px。底轨改为不参与布局、固定在容器底部的 `background-image`；活动 `::after` 的 `bottom:0` 必须与容器外底边重合，窄屏横向滚动时底轨仍保持可见。
- 共享 `TabsContent` 作为 Radix 可聚焦面板必须提供 `:focus-visible` 内描边（`--ring` 半透明 + `outline-offset:-2px`），不得只写 `outline-none` 让键盘用户丢失焦点位置。
- 工作区一级导航活动态 = 单条绝对定位指示器 + `::before` 表面扫光，不得为每个 Trigger 各画一条粗线；指示器按当前 Trigger 的 `offsetWidth` / `offsetLeft` 实测定位，320ms 平滑平移并监听容器尺寸变化，窄屏横向滚动时也保持贴边等宽；测量完成前必须由活动 Trigger 的底边和独立底轨兜底，禁止只依赖宽度从 0 开始过渡的绝对定位线。`::before` 必须显式 `position:absolute; inset:0; display:block`。指示器基层保持纯主色，叠一层白色窄高光做 560ms 单次扫过 + 低强度光晕，结束移出可见区、终态均匀；禁止再用 active 态 inset box-shadow 叠第二条粗线。指示器额外带一层常驻呼吸微光（`::after` 主色模糊层，2.6s `ease-in-out` 循环透明度 0.3–0.72），静态停留时也有光感。
- 一级 Tab 点击先在本地落位活动态并显示 `QueryLoading`，不等懒加载页面到达才移动指示器；路由确认后按 `pathname` 校准。
- `PageHeader` 的经线底轨单次扫过（约 1.25s，`animation-iteration-count:1`），只动 transform / opacity，结束移出可见区，业务页不再用 GSAP 重复驱动同一条底轨。
- 工作区一级导航在 hover / keyboard focus 时预加载目标页面模块，点击只负责挂载；预加载不得提前请求业务数据。低倍 CPU 下模块切换不得出现 long task，4x CPU 允许首载一次短任务，但必须保留 `QueryLoading` 反馈。

### 构造流程（测试项 / 用例）

- 测试项详情用「步骤 + 完成态 + 计数」表达构造顺序：`① 基本信息 → ② 测试方法（N 个子项）→ ③ 用例概况（N 条用例）`。完成步骤显示勾选并只播一次 180ms 缩放淡入；计数用等宽数字小标签，数量为 0 时不显示。
- 步骤按钮必须是 `<button aria-label="第 N 步 …，已完成/未完成">`，活动态用 aria-current="location"；它同时是滚动锚点，点谁亮谁、用户手动滚动后交还滚动位置。
- 构造顺序不在详情里靠长表单堆叠解决：用例列表保持在「用例概况」区块，空态必须写明下一步入口（去测试方法 → 子项卡片「生成用例」），不新增与 1:1 生成冲突的入口。
- 用例列表必须能按状态收窄：`全部 / 待执行 / 已通过 / 未通过` 四个筛选 chip 常显数量，切换只改视图；「全选」只作用于当前可见用例，切换测试项时筛选与勾选一起复位。
- 用例表至少保留「标识 / 名称 / 负责人 / 状态 / 操作」：负责人取 `testerId ?? designerId` 映射成员显示名，空值统一显示「未指派」，不隐藏列。

### 控件与状态

- 高频小控件只做短促状态反馈：Checkbox / Radio 勾选标记 150ms `fade + zoom`，主题按钮图标 150ms 交叉淡入；均只动 transform / opacity。
- 语义徽章和 active Tab 文字使用 `*-ink` 前景 token（警告用更深警告墨色），不在浅色底上直接用原语义色；浅色主色为 `oklch(0.535 0.15 153)`，保证白字主按钮与 12–14px 标签可读。
- 共享主按钮（`variant="default"`）**不带前侧竖条**：2026-10-22 用户明确否决——图标按钮前面多一条浅色轨会看成“不是正方形”，富文本状态按钮也会歪。拟态顶部内高光已按 2026-11-04 口径移除（见 [01 视觉方向](../01-基础视觉与组件/01-视觉方向.md) 按钮质感条），只保留 hover / focus-visible 单次 640ms 斜向纸面高光；高光依赖 `isolation:isolate` + `z-index:-1` 才能画在自身底色之上、文字之下。
- 纯图标按钮必须正方形：`size=icon*` 已有固定宽高；“文字收起后变图标”的按钮必须在同一断点把宽度对齐高度（需求树 `width:2rem` 对齐 `size=sm`），工具栏用 `min-width:1.75rem; padding-inline:0` 对齐 `size=xs`。验收直接量 `getBoundingClientRect()`，宽高差 < 1px 才算方形。
- 输入类控件（Input / Select / 复合输入 / Textarea）的焦点与错误视觉唯一事实源是 `web/src/styles/field-state.css`：焦点 = 1px 内嵌主色描边 + 2px 外环 + 低强度光晕，错误态换 `--destructive` 并带一次性入场与低频脉冲。禁止在组件里用 Tailwind `shadow-[]` 叠加（layer 优先级更低，是死代码）；所有轨道用 `box-shadow`，不得改 padding 或高度。
- 圆角统一 0–2px：AlertDialog / Field 组合容器 / Dialog 用 `rounded-sm`，Checkbox 2px，`SectionTitle` 等活动竖线为 0；不得残留 `999px` 胶囊线。
- 全站交互态 `transition` 缓动统一 `var(--ease-out-strong)`；除循环呼吸、骨架扫光等按语义保留的 `ease-in-out` / `ease-out`，不再散落浏览器默认 `ease`。新增组件复用现有 motion token，不单独发明近似曲线。
- 列表三态统一口径（2026-11-11）：加载用 `QueryLoading`/`InlineLoading`；查询失败统一 `QueryError`（带重试按钮），不得用纯文本提示；筛选/搜索无结果必须与「暂无数据」区分——文案说明是筛选导致，并提供「查看全部 / 清空筛选」恢复入口，且筛选切换后的列表用 keyed Fade 重新入场（问题单、项目列表、测试项同口径）。登录失败等一次性错误提示同样走 Fade 入场。
- 入场参数与代码对齐（2026-11-11，[use-subtle-reveal.ts](../../../web/src/hooks/use-subtle-reveal.ts) / [data-table-row.tsx](../../../web/src/components/shared/data-table-row.tsx)）：
  - 全局页面入场 `useSubtleReveal`：0.45→1 透明度 + 10px 上浮，单项 340ms、50ms 错峰（延迟封顶 300ms），首帧在 layout 阶段写入防闪帧。
  - 表格行入场：0.55→1 + 6px 上浮，18ms 行间阶梯（封顶 144ms）；虚拟化表格不做入场。
  - 列表行入场（问题单）：0.55→1，40ms 错峰（封顶 240ms）；筛选切换整表 0.85→1 / 160ms。
  - 路由与工作区模块切换：0.55→1 / 220ms，按 pathname 重挂；进度条挂载从 0 弹簧充能，分段进度条每段 26ms、14ms 错峰。
  - reduced-motion：以上入场在系统「减少动态效果」下全部直接终态（`prefersReducedMotion()` 提前返回，入场 Fade 用 `EntranceFade`）。

### 布局 · 滚动 · 性能

- 静态测试项的完善度卡只有一行说明时，容器必须 `height:auto` 随内容收紧（`data-state="static"`）；未完善 / 已完善状态才用固定高度对齐缺口 chip。
- 悬浮展开按钮保持固定盒宽，用 `clip-path` 显露左右范围，图标和文字只用 transform / opacity；禁止 transition `width / max-width / padding / gap`。
- 非虚拟化 `DataTable` 行首次挂载允许 180ms 透明度 + 3px 上浮入场，按行号最多错峰 144ms；虚拟化表格关闭行入场。
- 共享 `Skeleton` 使用低对比扫光（周期 1.8s）；`EmptyHint` 首次出现 180ms 透明度 + 3px 上浮。
- 需求详情“创建测试项”悬浮按钮以真实主按钮为滚动阈值，不用固定高度透明哨兵：动态查找最近可滚动祖先，滚动 / resize 用 rAF 合并读取位置，只有主按钮滚出上方才显示；≤1100px 固定到视口右下，`body` 保持 `min-width:0`，移动端只做 `overflow-x:clip`。验收覆盖桌面 body 内滚动、320px、滚回顶部隐藏。
- 侧栏主导航 active 左侧轨必须满行高：`::before { inset-block:0; left:0; width:2px }`，只让 `scaleY` / `opacity` 进出；禁止上下内缩，禁止用 inset box-shadow 另叠一条。需求树、测试项树等行级活动轨同样满行高。
- 共享 `Table` 内层 `table-container` 只承担横向滚动，必须显式 `overflow-y:hidden`：行入场 `translateY(3px)` 会让纵向溢出回落为 `auto`，闪出 18px 滚动条并挤窄表格。

### 全局快速切换、列表易用性与模块入场（2026-10-24）

- 参考 OpenDesign 的 Linear 精确层级、Raycast 键盘优先与 Superhuman 单次主视觉：只保留一个主色强调、低幅状态反馈和一次性扫光，不引入全屏循环背景、漂浮卡片或第二套业务色彩。
- 系统顶栏与工作区顶栏均提供 `Ctrl+K` / `Meta+K` 快速切换；系统页覆盖项目列表、新建项目、字典配置、用户管理，项目上下文补充项目详情与项目工作区；面板打开时默认选中当前页面，支持搜索、上下键、回车、Esc，悬停条目只预加载对应模块；`contenteditable` / TipTap 编辑器内不抢占快捷键。
- 快速切换弹层顶部只跑一次 620ms 扫光；条目选中态用背景、1px 边框和 2px 左轨表达，图标只做不超过 1.03 的缩放；模块卡片首次出现使用 200ms、4px 上浮入场并按卡片错峰最多 96ms。
- 全局快速切换只做页面导航，不新增业务动作；新增动作必须走对应页面现有入口，避免把未确认的业务逻辑塞进命令面板。
- 项目列表把项目表放在筛选与 KPI 之后、风险/待办摘要之前，保证首屏能看到核心数据；1760px 以下隐藏平台、更新时间、测评性质、软件类型和研制单位，优先保证标识、名称、等级、负责人、用例执行、未闭环、状态与操作可读；技术字典与用户管理增加即时搜索、结果计数、清空与无结果恢复入口；测试项内查找补显式清空按钮。
- 全局快捷键不得叠开第二个模态：已有 Dialog / AlertDialog / Sheet 打开时，`Ctrl+K` 不打开快速切换；快速切换自身打开时仍可用同一快捷键关闭。

### 全局指针聚光（2026-10-26，2026-11-04 收窄）

- 全站只保留一个文档级指针监听器：`pointerover` 定位最近的 `[data-spotlight]`，`pointermove` 只写入当前表面的 `--spotlight-x / --spotlight-y`，用 `requestAnimationFrame` 合并更新，不触发 React 状态更新。
- `Card` 的聚光与扫光改为显式开启：只有展示型叶子卡片（项目列表 KPI）传 `spotlight` / `sheen`；高频交互卡片、表单卡片和包含子卡片的父卡片默认不开启，避免鼠标扫过时干扰操作。
- `Card` 扫光通过 `sheen` 开关追加一个仅用于展示型卡片的 `span`，聚光使用 `::after`；交互卡片默认不追加，含图片的卡片不开启，避免破坏 `img:first-child` / `img:last-of-type` 的既有圆角规则。`PageHeader` 与工作台/需求/测试项/用例/资料 Hero 使用共享 `SpotlightSurface` 的子 `span`。
- 光斑只在 hover / focus-within 出现，透明度过渡 180ms；仅启用 `(hover: hover) and (pointer: fine)`。浅色模式扫光改用主色/信息色混合，不再使用在白底上不可见的纯白高光。
- 应用范围限于展示型 Card、PageHeader 和主要 Hero；禁止铺到表格、虚拟树、输入框、弹窗内部及行级 hover。

### 页面级 HUD Tab 与滚动（2026-11-04）

- 页面级 Tab（项目详情、DC 受审文档/审查单）统一使用共享 `Tabs` 的 `hud` 变体：1px 主色边框 + 内描边、等宽分段、活动态角括号与底部光束，文字强制水平/垂直居中；扫描光只走 `background-position`，不新增可滚动溢出。
- HUD Tab 的扫描光只在挂载后单次播放 1.6s，不做常驻循环，避免在最高频页面持续重绘整条轨道；活动光束 2.6s 呼吸。窄屏保留横向滚动，不压缩文字。
- 页面级 Tab 切换统一由 `useResetScrollOnTabChange` 处理：等新面板完成布局后再平滑滚顶，避免内容高度骤变把动画打断成瞬移。筛选 Tab、列表内 Tab 和各自独立滚动的面板不得调用。

### 工作区顶栏底边流光（2026-11-05）

- 工作区顶栏（`.workspace-topbar`）底边是 2px 整宽流光带：整条宽度覆盖周期渐变，颜色缓慢流动——`background-size: 200% 100%`、8s `linear infinite` 平移一个周期无缝循环，无 box-shadow、无亮段边界、无扫光块。渐变图由两段相同周期组成、首尾同色，循环接缝不可见。
- 用户口径（2026-11-05 两次修正）：不要生硬扫光块、不要阴影，宽度必须整条，只让颜色流动；色序为**红 → 紫 → 绿 → 白**循环，浅色主题用 500 档饱和色（`#ef4444 / #8b5cf6 / #16a34a / #ffffff`），深色主题用 400 档亮色（`#f87171 / #a78bfa / #4ade80 / #ffffff`），保证两种主题都明显。
- 光带动画走 `background-position`（2px 条带绘制成本可忽略，与 HUD Tab 扫描光同口径）。样式落在 `workspace-topbar.module.css`，不写进全局 `project-workspace.css`；彩虹 hex 为用户点名色序，属「不新造色值」规则的明确例外。
