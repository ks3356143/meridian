# 反馈、表单与控件

> 返回 [前端体验](../07-前端体验.md)

## 反馈

- 操作成功、失败和网络异常统一使用 `sonner`，全局位置顶部居中。
- 表单字段校验错误保留在字段附近。
- `Toaster` 必须开启 `richColors`，否则成功、警告、错误的自定义语义背景和边框变量不会应用到 toast 本体；深浅色主题下都必须检查实际渲染结果。
- `sonner` 成功、警告、错误 toast 背景统一使用 `var(--popover)`：浅色模式必须是白色，暗黑模式使用主题暗色弹层底色；边框直接使用 `--success`、`--warning`、`--destructive`，不得改成白色或中性边框。
- sonner 顶部 toast 必须整体让开固定顶栏：Toaster 顶部安全偏移统一引用 `--toast-safe-top`（基础顶栏高度 + 12px 间距），`offset` 与 `mobileOffset` 同步设置；导航 View Transition 期间顶栏快照层不得遮挡 toast，深浅色与窄视口都要验证。
- 401 时清理本地登录态并回到登录页。
- 语义色体系：主题/成功为绿色，警告为橙色，错误/危险为红色，信息为蓝色或中性色。品牌绿只代表主品牌和主操作，不得吞并警告、危险、停用和信息语义。
- 启用/停用必须一眼可辨：启用用 success 绿色和确认图标，停用用 danger 红色、关闭图标和“停用”文字；将执行停用操作的按钮使用 destructive 红色，启用操作不得使用危险色。
- `sonner` 按结果选择语义：成功 success，停用/需注意 warning，失败 error，说明 info。

## 表单层级

- 全局 `Textarea` 使用成熟的 `react-textarea-autosize` 方案：不显示原生右下角拖拽手柄，按内容自动增高；默认提供合适的基础行数和最大行数，超过最大高度后内部滚动。业务可在语义明确处覆盖基础行数（例如删除原因 3 行、需求描述 5 行），但不得恢复拖拽手柄或绕过统一组件。
- 字段标签使用 `font-semibold` 与 foreground，和辅助说明、占位文案形成三级明显层级。
- 字段标签与输入框、下拉框保持 `for/id` 关联以保留语义，但点击标签不得激活或聚焦关联控件；控件仍通过直接点击和键盘获得焦点。
- 输入内容使用 foreground 和中等字重；placeholder 使用独立弱色和常规字重，禁止复用 `muted-foreground`。
- 必填字段展示必填标记；多选字段同时提供“待选择 / 已选”状态，不只用颜色表达。
- 长表单底部固定操作区展示当前缺失项，提交错误点名缺失字段或分组。
- 提交表单必须使用 `noValidate` 的自定义校验，禁止浏览器原生气泡。字段错误通过红色边框、阴影或字段内提示表达，并可用 `sonner` 汇总。
- 字段错误文字出现与消失必须成对动画：出现时做 180-240ms 的淡入与轻微上移，错误占位高度使用 `grid-template-rows: 0fr -> 1fr` 平滑展开；用户修正错误后做 160-220ms 的淡出、轻微上移与 `1fr -> 0fr` 收起，并用等值负 margin 抵消字段 gap 造成的瞬时跳动。退出帧保留视觉内容但移除 `role=alert` 并标记 `aria-hidden`，动画结束后再卸载；不得造成横向位移。`prefers-reduced-motion` 下关闭位移和高度动画，错误修正后直接静态消失。
- 输入框和选择器 focus 时同时出现品牌色边框、内描边、静态 2px 荧光 ring 和外扩散阴影。
- 校验错误同时出现红色边框、2px 起步的红色荧光脉冲和外扩散阴影；错误状态优先于 focus 保持红色语义。
- 状态切换使用 240-320ms 平滑过渡；错误先入场淡入，再进入循环脉冲。reduced-motion 下关闭动画并保留静态三层阴影。

## 弹窗与日期

- Dialog 关闭期间禁止 remount：编辑器组件的 `key` 只能在打开时变化，关闭瞬间换 key 会杀掉 Radix 退场动画。
- 日期选择使用 `Popover + YearMonthCalendar`（react-day-picker 日期网格 + shadcn Select 年月切换头部），禁止原生 `input[type=date]` 和 react-day-picker 原生 select 覆盖层。
- 弹窗表单同样适用表单校验铁律：`noValidate`、自定义校验、`aria-invalid` 红边框阴影、字段内提示、`sonner` 点名汇总。
- 弹窗内必填字段展示红色 RequiredMark。

## 标签页与分段筛选

- 页签与筛选分段一律使用组件库 Tabs（shadcn/Radix）。
- 默认使用胶囊分段变体：激活态背景高亮、图标、计数徽标。
- `line` 下划线变体用于工具栏和紧凑场景：明确底边、品牌色 2px 激活下划线。
- 禁止手搓按钮组充当筛选器。

## 控件光标与图标

- Tailwind 4 preflight 把按钮光标重置为 default，必须全局恢复：`button`、`[role="button"]`、`[role="combobox"]`、`a[href]`、`summary` 未禁用时 `cursor: pointer`。
- 下拉框触发器 hover 同时有边框加强和轻背景反馈，不能只依赖 focus 态。
- 功能图标使用语义色或继承前景色，禁止裸白色图标；primary 按钮内部图标随白色前景除外。
- 关闭按钮 X 使用 muted-foreground，hover 加深为 foreground，禁止语义色圆底白叉。

## 炫酷组件参考

用户明确要求“炫酷组件”时，优先使用 React Bits：shadcn registry `@react-bits` 已在 `web/components.json` 配置，组件落位 `src/components/ui/`，动画依赖 `motion` 并必须接入 `useReducedMotion`。Aceternity UI、Magic UI 等仅作效果与交互思路参考；引入前必须适配 React 19、Tailwind CSS 4、shadcn/Radix、直角工程风格、深浅色、无障碍和 `prefers-reduced-motion`，不盲目复制与主题冲突的样式。
