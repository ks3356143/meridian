# 专项证据与轮次基线

> 返回 [专项数据集与大规模生成](../18-专项数据集与大规模生成.md)

## 背景

本节来自对一组真实第三方测试交付 DOCX 的结构审计。该组文件覆盖大纲、首轮说明、首轮记录、问题报告单、回归说明、回归记录和测评报告，代表了当前需要支持的最复杂项目形态。

审计只吸收通用能力，任何参考项目特有的业务字段、业务枚举和表格语义都不进入通用需求。

## 规模事实

| 指标 | 审计结果 |
| --- | --- |
| 测试规模 | 37 个测试项、354 个设计用例；首轮动态执行 351 个用例。 |
| 回归规模 | 3 个回归用例，另含 46 条专项证据行。 |
| 专项数据 | 首轮说明和记录含 1268 行专项数据表；报告含 1408 行专项数据表。 |
| 图片规模 | 首轮测试记录 199 张图片，约 33.5MB，全部为唯一哈希。 |
| 文档规模 | 首轮测试记录约 156 页、99 张顶层表格、247 个绘图节点。 |
| 版本演进 | 需求规格说明 V1.02 到 V1.03，被测软件 V1.40 到 V1.41。 |

审计还确认了三个容易返工的口径：

- 硬件环境表在不同文档中存在 `IP`、`检定有效期` 等差异列，表格列必须来自模板或块 schema。
- 大纲的 34 个测试项、报告的 37 个测试项来自需求版本演进，必须用轮次基线解释。
- 用例表数量、报告用例统计、步骤数量和专项数据行数不能混用；每个统计指标登记数据源和口径。

这些数字是后续性能预算和交互设计的最低压力标准。

## 专项证据数据集

### 定位

专项证据数据集指不属于通用测试项 / 用例模型，但需要参与筛选、统计、追溯和 Word 输出的大规模外部数据，例如外部比对数据、接口报文、参数矩阵、日志抽样、性能采样等。

专项数据集不是测试用例：

- 不为每行数据生成测试项或用例。
- 不把行数据展开成问题单。
- 不把业务列名硬编码进通用模型。
- 可关联某个测试项或用例，作为其证据来源。
- 可按筛选条件生成回归子集，例如“上轮不一致且本轮需验证的行”。

### 模型

`evidence_datasets`：

- `id`、`project_id`、`round_id`
- `kind`：已登记的数据集种类，如通用比对表、通用采样表。
- `name`
- `source_asset_id`：来源附件。
- `source_version`、`captured_on`
- `schema_version`
- `row_count`、`status`
- `summary_json`

`evidence_dataset_rows`：

- `id`、`dataset_id`、`row_index`
- `payload_json`
- `result`、`category`
- `previous_row_id`
- `linked_test_item_id`、`linked_case_id`、`linked_issue_id`

数据集种类必须登记 schema、默认列、校验规则、索引字段、统计口径和渲染器。未登记种类不能导入。项目特有数据只能作为某个项目模板启用的数据集实例，不能成为核心业务表的固定字段。

### 交互

- 导入采用流式解析和分批事务，不整表读入内存。
- 导入前展示来源、版本、行数、列结构和关键唯一性校验。
- 导入后先进入预览和校验态，用户确认才可用于生成。
- 大表使用虚拟滚动、服务端分页和筛选，不做全量前端渲染。
- 差异行、未闭环行、回归通过行用状态语义标识。
- 支持按数据集生成统计摘要和专项附件表。
